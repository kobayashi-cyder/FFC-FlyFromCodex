# BANC888 7.10 — 操作画面と添付の修正

会話画面の上部に「会話」「新規」「設定」とオンライン／オフライン切り替えを表示する。入力欄の操作は「添付」「音声入力」「停止」「送信」にする。ヘッダーのSVGに寸法がなかった問題、ライト表示でマイクが白くなる問題、旧44px固定幅でラベルが折り返す問題を修正した。設定にはモデル、A1111接続、動画品質、音声、表示だけを置き、APKと画面のバージョンを表示する。

切り替えは独立した `FFC_EXECUTION_MODE_V1` に保存する。A1111接続先や生成設定が不正でもオフラインへ切り替えられる。既存の接続モードは初回のみ引き継ぐ。オフラインへ切り替えたらモデルとA1111の実行を中止し、既存の通信ゲートを維持する。LANの外部モデル／A1111接続もオンラインモード扱いであり、端末内生成と区別する。

## 添付

Androidのドキュメント選択画面で選んだUTF-8の文章・Markdown・JSON・CSV・ソースコードを読み込む。1ファイル128KB以内、先頭12,000文字まで、1送信4ファイル／合計24,000文字まで。切り詰めは画面で明示する。PDF、画像、音声、動画、バイナリ、UTF-8以外は未対応として表示する。画像の内容認識や動画理解ができるとは扱わない。

添付の下書きは会話ごとに保持し、ファイル選択を開いた時の会話へ追加する。送信成功時だけ下書きを消す。送信済みの名前と本文は会話履歴に保存し、JSONにも容量制限の範囲内で含める。要約処理へはファイル名ではなく本文を直接渡す。資料作成・コード生成は同じ会話の文脈を参照する。内容理解は内蔵の根拠抽出であり、汎用LLM水準の理解を保証しない。

ネイティブの選択結果は `content:` URIのみ受け付け、最大4件に制限する。キャンセル、ページ遷移、Activity破棄、ネイティブセッション変更時は未処理のコールバックを終了する。WebViewの包括的なfile/contentアクセスは無効のままにする。

## 更新と起動

APK更新時はAPK内蔵の画面で起動する。会話のWebViewストレージは消去しない。保存済みLive画面を使う場合は起動時にmanifestのスキーマ・全ファイル・SHA-256を検証し、不完全／不互換な一式を拒否する。キャッシュのHTMLとAPKのJSを混在させない。

画面部品は短いポーリング期限を廃止し、DOMと会話UIの準備通知で配置する。設定は切り替えバーの読込みに依存しない。Dev Liveの診断部品を会話画面へ仮配置せず、設定の準備を待つ。

## 検証

Node: 切り替え（破損A1111設定／保存容量エラーでも通信ゲート維持）、添付（UTF-8/BOM/容量/非対応/バイナリ/切り詰め）、既存回帰テスト。

Chromium: Android同様の一括ランタイム注入、320/360/390pxの縦画面と横画面のヒット領域、ファイル選択、会話別下書き、要約、添付情報を使う資料作成、JSON出力、更新後のモード保持、部品の再配置。

Android: `ChatControlsIntegrationTest` は実タッチイベントによる設定・モード切り替えと、ファイル選択結果をWebView FileReaderへ渡す経路を検証する。`LiveBundleUpgradeIntegrationTest` は互換キャッシュ、欠落ファイル、APK更新後の内蔵画面復帰を検証する。既存の太陽光発電テストは、旧ネット検索への固定期待から現在のオフライン会話経路の内容・通信なしの確認へ変更した。
