# 会話・資料・開発ワークスペース

v7.11では、既存の会話分離を維持したまま次を追加する。

- 会話検索: 会話名、本文、送信済み添付名を日本語を含めて絞り込む。検索解除で全件へ戻す。
- 会話別下書き: 入力中の本文を会話IDごとに localStorage へ保存し、会話切替とアプリ再起動後に復元する。送信が成立して入力欄が消去された場合だけ、その会話の下書きを削除する。保存失敗は画面へ表示する。
- 資料再利用: 初期表示は現在の会話だけ。別会話の資料は「全会話（明示的に選択）」へ切り替えた場合だけ候補に出し、選択した資料だけ現在の会話へ再添付する。
- 生成物一覧: 資料・コードを開く、コピー、保存、再添付する。全会話表示は明示操作時だけ。
- 添付制限: 4ファイル、1ファイル128KB、先頭12,000文字、合計24,000文字を維持する。

自動送信、生成コードの自動実行、別会話の内容の自動混入は行わない。設定画面には生産性機能を移さず、会話サイドバーと会話入力欄から操作する。
