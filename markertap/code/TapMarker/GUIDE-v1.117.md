# MarkerTap v1.117 — 復帰上限後の画面再作成・閉じる結果の確認

`jp.tapmarker.lite` / versionName `1.117` / versionCode `120`

## インストール

1. 旧版の「全停止」を押します。
2. `MarkerTap-v1.117-display-recovery.apk` を上書きインストールします。
3. ユーザー補助を確認し、端末内接続を再開して仮想画面の自律を開始します。

元と同じ署名証明書を使用します。通常の上書き更新で設定を引き継ぎます。今回の変更で起動幅320px、表示密度、対象アプリの選択、通常タップの方式を自動変更しません。

## 修正内容

### 復帰上限後

通常復帰3回・タスク再起動2回の上限に到達した場合、または入力先の復帰が上限に達した場合は、30秒待ってから対象の仮想画面だけを1回再作成します。

対象画面のImageReaderを交換して古いフレームを無効にし、その画面を解放、新しい画面を同じ寸法・密度で作成して対象ゲームを起動します。他画面の入力エポックや接続のarm状態を再設定しません。ゲームのアプリデータは消去しません。

再作成の受付を主画面への復帰成功とは扱いません。新しい画像で主画面を2回・350ms以上確認した場合に、その復帰エピソードを完了します。再作成の操作は30秒、受付後の主画面確認は90秒を上限とします。未確認のままなら理由と画像付き診断を保存して該当画面を個別停止し、他画面の処理を継続します。

タスク再起動の回数は再作成後も保持します。再作成した画面には閉じる操作の有限な予算を新しく与えますが、主画面未確認のまま画面再作成を繰り返すことはありません。個別停止後は端末上で該当画面を確認し、必要なら全停止から自律を開始し直してください。

この自動再作成は標準プリセットの仮想画面が対象です。独自編集・学習グラフ、終了状態、保護状態を再作成で突破する処理ではありません。

### ×タップと結果確認

画面上部などのポップアップの×は、位置を新しい画像で2回・200ms以上確認してから操作します。×が移動したら位置の確認をやり直します。下端の閉じる操作は従来の検出方式と回数制限を使います。

入力完了通知だけで「閉じた」とは扱いません。操作から800ms以上待ち、同じ表示が残る場合は新しく検出した位置へ再試行します。同じ未解決表示への要求は2回までです。消失の確認にも、新しい画像2回・350ms以上を使います。消失だけで主画面を確認したことにはしません。

### 診断記録

農園の限定ミッション案内について、画像距離と照合領域を保存します。閉じる操作の要求回数、表示残留・消失確認、画面再作成の段階も残します。

進行エラー時に、対象画面のウインドウ所有パッケージ、表示範囲、フォーカス、および対象ゲームの名前付き操作部の範囲と画面内に見える部分を記録します。取得数には上限があります。SDKが操作部をユーザー補助へ公開しない場合、画面外のボタンの存在や位置は推測できません。

## 今回の再現素材

`incident-1792493963517-c0fa64d7-66.zip` の農園うさぎの診断とJPEGを使用しました。案内の×が `(295,151.5)` から `(289,159.5)` へ動く画像、および暗い読み込み画面を使い、検出、再試行、上限後の段階遷移を確認します。

`tests/incident66-replay.bin.gz` は添付JPEGをRGBに復号した4画像です。JPEGの元となった端末内画像の無劣化データではありません。入力完了、画面再作成、時刻進行はホスト上の模擬です。

## 検証と限界

新規の `DisplayReplacementTest`・`DisplayRecoveryTest`・`Incident66ReplayTest` と、従来のcore回帰を実行します。最終結果は `VALIDATION-v1.117.json`、`tests-v1.117.log`、`apk-verification-v1.117.json` を参照してください。

Pixel 10 / Android 17はこの環境へ接続されていません。端末上の実タップ到達、実際の画面再作成、すべての広告からの復帰、報酬加算、4画面の長時間稼働は未確認です。実機未検証の動作を成功扱いにしていません。

## 再ビルド

Android API 35、Build Tools 35.0.0、Java 17、Python 3、ripgrep、C/C++コンパイラを使用します。

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/lite-development.jks \
bash build.sh

ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
```

秘密鍵はAPK、ソースZIP、差分ZIPに含めません。fullグループの追加4録画は、従来版と同様に素材の制限があるため通常coreの対象外です。
