# Specialist Tool v2 Handoff

Branch: banc888-apk-thread-router

Implements the cross-chat design: Artifact IR -> skill routing -> generator -> verifier -> bounded local repair -> experience feedback.

Preserved invariant: O0/connectome/CPF/O1-prime remain control/routing data. F42/F46 are control/search bodies, not trained general generators.

Code: CodeIR plus generate/revise/debug/refactor/test/convert/optimize, local syntax and requirement validation, deterministic recipe fallbacks.
Image: ImageIR for subject, composition, light, style, palette, aspect and size; O2 generation plus non-empty-scene validation and retry.
Voice: SpeechIR for listen/speak/status/configure, language, rate and pitch, with native Android ear/mouth.
Documents: DocumentIR for type, audience, tone, sections, constraints and quality; DOCX/Markdown/HTML/TXT. Native DOCX now formats headings, bullets and code blocks.
Experience: 96-entry bounded success/failure history. High-quality requests can run bounded F42 control; completed success adapts, completed failure rewires. O0 is never mutated by this layer.
