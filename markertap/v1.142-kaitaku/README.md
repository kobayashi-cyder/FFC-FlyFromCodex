# MarkerTap v1.142：開拓うさぎの独立した開始・判定

v1.141 / PR #22 / `87d5f414600fa0427b8d4da8dd0cb84b5fdfd7aa`を基に、`com.kurashiru.kaitaku.usagi`専用の設定を追加した更新候補です。versionNameは`1.142`、versionCodeは`145`です。

## 変更

- 対象一覧と表示名に「クラシル開拓うさぎ」を追加。設定・状態ID・見本をパッケージ別に分離。
- 空の設定を読み込んだときに元の保存内容を退避し、開始判別・通常プレイ・広告待ち・復帰確認をインストール。既存の空でない編集設定、ウインドウ相対設定、読込エラーは上書きしない。
- 実画面の開始時に前面アプリと設定の所属を再確認。農園用の状態を開拓うさぎの設定として実行しない。通常プレイは独立したタッパーを使い、マーカー追加を要求しない。
- 録画の開拓ボタンの左右2領域を独立照合。押下時の変化を含む4場面を確認し、広告・ストア・ホーム画面を主画面として許可しない。判定に使うのは画面の一部の画素で、画面解像度やDPIは変更しない。
- 「このままはじめる」は見出しと文字の2領域で確認し、任意のCMボタンより下にある再開操作へ進む。消失・主画面の再認識を待って連打を再開する。
- 広告の閉じる判定、復帰回数の上限、1500msの鮮度制限、実行トークンと対象ウインドウの検証、v1.141の報酬処理と画像取得監視を継承。

## 観測と限界

診断ZIPはv1.140、実画面、`STATE_MISSING`、開拓うさぎ、空の実行状態を記録しています。選択対象には増えうさぎ・農園うさぎが残り、判定名には`farm-default-home-lost`が残っています。対象一覧は仮想画面側の設定でもあるため、その違いだけを実画面の停止原因とは断定していません。

ソースには開拓うさぎの標準定義がなく、空の状態を用意するための処理もありませんでした。本改修はこの不足を補います。参照元は`reference-provenance.json`に記録しています。テスト保存物はボタン周辺の領域のみで、残高・操作パネル・広告バナー・署名鍵を含みません。

Pixel 10の録画1本に基づく初回対応です。実機でのインストール・入力、Pixel 10以外の端末、未知の開始ポップアップ、報酬の実残高、デイリーミッション完了、長時間無人運転は未検証です。任意の広告を必ず終了できることは保証しません。

## 更新・確認

1. 旧版で「全停止」を押す。
2. 会話添付の`MarkerTap-v1.142-signed.apk`で既存アプリを更新する。
3. 開拓うさぎを前面にし、「自動開始」を押す。
4. 「開拓うさぎ：開始・画面判別」から通常プレイへ進み、広告中に連打が保留されることを確認する。
5. 「このままはじめる」の後、主画面を再認識して開拓を再開することを確認する。

旧版をアンインストールする必要はありません。実機で停止した場合は、版番号と「画像付き診断を共有」のZIPを照合します。

## 再構築

Java 17、Python 3、Android API 35 / Build Tools 35.0.0、JADX 1.5.3を使用します。既存の署名鍵を指定した場合だけ従来証明書で署名します。未指定時は未署名APKを生成します。

```bash
python3 markertap/v1.142-kaitaku/restore_project.py /tmp/markertap-v1142-source
TAPMARKER_KEYSTORE=/private/path/original.jks \
python3 markertap/v1.142-kaitaku/build_ci.py \
  --sdk /path/to/android-sdk \
  --jadx /path/to/jadx-1.5.3-all.jar \
  --output /path/to/results
```

検証は録画由来の17場面、44項目の状態・操作点・誤認識テスト、既存のcore/host試験、障害再生8件、実際のAPK内部15箇所の接続を対象にします。ビルド成功・署名検証は実機運転成功と区別します。
