# MarkerTap v1.74 — 農園の報酬を閉じる・プレイアブル広告から復帰

v1.73のAPK内BANC自律、ゲーム間ノウハウ共有、録画による比較・改修・再検証を引き継いだ更新です。パッケージは `jp.tapmarker.lite`、versionCodeは77です。

## 更新と再開

1. `MarkerTap-v1.74-close-ad-fix.apk` を現行版へ上書きインストールします。v1.73と同じ署名を使用します。
2. 対象アプリを開き、操作パネルの「自動開始」を押します。
3. 仮想画面の場合は、更新したAPKで端末内の実行部を起動し直してから、対象画面の自律を開始してください。実行部の通信プロトコルは75のままです。

今回の添付画像には「自律OFF」「停止理由：画面が消灯…」と表示されています。消灯による停止中はタップを送りません。更新後も「自動開始」で再開してください。

## 農園うさぎの「閉じる」

添付された2026年10月13日の「コインゲット！」画面は、v1.73の画像見本では認識できませんでした。報酬状態・画面判別状態で「閉じる」の操作が成立せず、タップ座標も取得できないことを元の検査用ランタイムで再現しています。

今回の画像から、コイン獲得メッセージと「閉じる」の文字をそれぞれ照合する見本を追加しました。両方の見本が一致した画面を確認し、操作直前にも表示を再取得して、現在の閉じるボタン内を押します。収穫ボタンのマーカーとは別の操作です。

従来の通常画面・仮想画面の見本は維持します。独自に変更した画像・領域は優先されるため、独自設定の不一致がある場合には「録画で改修」を使用してください。

## プレイアブル広告

| 表示・状況 | 処理 |
| --- | --- |
| 左上・右上に白い×または黒・灰色の× | 背景との対比と×の形を確認し、現在の印の中心を押す |
| 可視・有効な「閉じる」「スキップ」「Close」「Skip ad」など | 対象アプリ・対象画面の操作領域から位置を取得。通常の文字ボタンは上部の隅に限定 |
| 「戻る」後などに「広告を閉じる」「Close ad」の確認ボタン | 明示的な広告終了の文字なら中央の確認ボタンも対象にする |
| 「プレイ」「Play now」「インストール」、秒数、＋、曖昧な次へ | 新しい広告終了操作として選ばない |
| 広告の終了印が見つからない | 通常の広告状態では最初に30秒待ち、対象画面で「戻る」を最大2回試す |
| 「戻る」で復帰できない・入力が拒否された | 既存の登録アプリへの復帰処理へ移る |
| ゲームまたは報酬などの登録済み表示が戻った | その表示に対応する操作を優先し、広告の戻る回数をリセットする |

コイン落とし・お店屋さんで既存の報酬広告が設定されている場合、従来の120秒の待機上限は維持します。終了印が確認できれば上限前でも操作します。実際の広告SDKが入力を受け付ける時刻、終了・報酬の扱いは広告側の実装によります。

通常画面、分割画面、仮想画面に反映しています。分割画面の「戻る」は対象アプリが操作対象の場合に限り、仮想画面ではその画面IDへ入力します。広告の回数・結果・状態は画面ごとに管理します。BANCが広告状態で提案する未知の操作も、閉じる操作に限定します。

## 検証範囲

- 添付画像の画素による報酬分類とボタン内のタップ座標。
- 画像の再サンプリング、画面の移動、画面サイズが変わった後の古い座標の拒否。
- 獲得メッセージまたは閉じる文字が消えた場合の操作保留。
- 既存の農園ダイアログ・広告・他ゲーム画像への誤認識の回帰検査。
- 広告の終了文字、両色の×、プレイ・インストール・秒数・＋の除外。
- 終了印の優先、待機、対象画面で戻る、登録アプリへ復帰する順序と画面別の回数管理。
- BANC、録画改修、相対座標、入力中断、巡回、接続・暗号などの既定ホスト検査。
- APKの署名、従来版との証明書一致、DEX、4種類のCPU向けライブラリ、16KB配置。

検査ログは `tests-v1.74.log`、詳細は `VALIDATION-v1.74.json` に含めます。Android実機は接続されていません。今回のプレイアブル広告の画像・録画も未提供のため、その広告自体を操作して終了できたという検証ではありません。報酬付与やすべての広告からの終了を保証するものではありません。

## 再ビルド

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk TAPMARKER_KEYSTORE=signing/lite-development.jks bash build.sh
ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
```

SDK platform 35・build-tools 35.0.0とJava 17が必要です。ソースに含まれるのは既存の開発用署名鍵です。過去の4録画を使う任意の `full` 検査には、従来から別途の録画フィクスチャが必要です。
