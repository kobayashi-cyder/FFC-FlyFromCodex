# MarkerTap v1.99：仮想画面・縮小表示

仮想画面は従来版から対応しています。本版はv1.97の完全ソースへv1.98の農園広告エラー復帰を適用し、小窓の縮小と入力座標を修正した更新版です。

## 操作方法

1. 旧版の「全停止」を押し、`MarkerTap-v1.99-virtual-preview.apk`を上書きインストールします。
2. 仮想画面を接続し直し、「自動開始」を押します。
3. 操作パネルの「画面」で100%・75%・50%・35%を選びます。展開時の「仮想画面の表示サイズ」からも選べます。100%は通常の小窓サイズです。
4. 見出しだけにする場合は「最小表示」を選びます。「仮想画面を拡大表示」で100%に戻ります。

表示倍率は保存され、次回作成する小窓にも適用されます。倍率変更ではゲームを再起動せず、仮想画面のID・内部解像度・各ゲームの状態機械を維持します。小窓を移動しても内部の入力座標は変わりません。

## 改修内容

| 対象 | 動作 |
| --- | --- |
| 自律の画像判定とタップ | 小窓の見かけのサイズではなく、各仮想画面の内部画像とローカル座標を使用します。 |
| 手動タップと実演学習 | 実際の表示画像の余白を除いて座標変換します。上下・左右の余白へのタップは送りません。 |
| 縮小と最小表示 | プレビュー用ウインドウだけを変更します。内部のImageReaderとSurfaceは維持します。 |
| 回転後の表示復元 | 基準サイズを別に保持し、回転のたびに小窓が縮み続ける経路を除きました。 |
| 操作途中のサイズ変更 | 未送信の手動タップ・実演の座標を無効化し、異なる表示サイズの座標を混ぜません。 |
| 農園の広告表示失敗 | v1.98のOK確認と復帰処理を含めます。修正キットに不足していたレーンごとの状態変数も補いました。 |

最小表示ではゲーム画像への手動タップはできません。手動操作・学習の際は画像を表示してください。縮小は主にプレビュー負荷を減らす機能で、ゲーム本体のメモリ使用量を大幅に減らすものではありません。

## 検証

`test-virtual-preview.sh`で座標・表示サイズ41項目、録画6743由来の縮小表示座標59項目、広告エラー認識・復帰状態34項目の計134項目が合格しました。縮小表示の検査は内部画像とプレビューの座標対応をホスト上で再現したものです。

coreのJVM検査106組と模擬ADB8ケースが合格しました。最後に追加した操作パネルの「画面」ボタンは、再ビルドと関連する仮想画面・座標検査7組（216項目）で確認しました。詳細は`VALIDATION-v1.99.json`、`tests-v1.99.log`、`tests-v1.99-final.log`に記録しています。Android実機は接続されていません。端末での縮小中の長時間連続稼働や、すべての広告での成功率は未確認です。

## 再ビルド

Java 17、Android SDK platform35/build-tools35.0.0、Python3、ripgrepを使用します。暗号検査にはC/C++コンパイラが必要です。

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/lite-development.jks \
bash build.sh

ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
```

修正キットのみの場合は、v1.97完全ソースの上に展開してからビルドします。APKは同梱されません。

仕様参照：[VirtualDisplay](https://developer.android.com/reference/android/hardware/display/VirtualDisplay)、[GestureDescription.Builder](https://developer.android.com/reference/android/accessibilityservice/GestureDescription.Builder)。
