# MarkerTap v1.120 接続維持・実行中セッション復旧
v1.119を基に、通常解像度・DPIと領域取得を維持します。

## 改修
- 起動途中でWi-Fiが切れた場合、すでにBinderで接続済みの実行部をネットワーク待機の取消しで終了させません。
- ADB出力の読取りが切れても、同じ起動トークンの実行部とのBinder接続が成立していれば起動成功として扱います。異なるトークンや全停止後の接続は採用しません。
- 手動開始した仮想画面の実行中に実行部が終了した場合も、対象一覧と実行状態を保存してWi-Fi復帰後に再接続・画面再作成・再認識を進めます。手動モードの待機中には接続を開始しません。
- 全停止・消灯による停止・明示的な復旧取消しで自動復旧を取り消します。
- 実行部が繰り返し終了する場合は、10分間に3回までの復旧要求で打ち切ります。明示的な開始操作で再試行できます。
- 明示的な全体画像取得で例外またはOutOfMemoryErrorが発生したとき、ワーカーから未処理のまま伝播させず取得失敗として通知します。

## 使用
現行版を全停止してから上書きインストールし、「端末だけで接続」から開始してください。
起動時と実行部の再起動時にはWi-Fiが必要です。起動済みの実行部とのBinder接続が生きていればWi-Fi切断だけでは終了しません。
実行部自体が終了すると、Wi-Fiが戻るまでは仮想画面の再起動を待機します。
ペアリング登録やアプリデータを消去する必要はありません。
本体画面に移して操作するフォールバックは行いません。
