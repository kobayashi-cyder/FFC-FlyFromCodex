# v1.153 signed release integration gate

Version 1.153 (versionCode 156) uses exact authentic signed v1.151 APK SHA-256 ae2db2972780e50966f26243ab5fd8f2f6d9106056eeda233a2d75a1f9535dab.

The new DEX overlay preserves original APK resources and method bodies, adding a per-window screenshot stale policy and a compatibility route from Shizuku privilege requests to the app-owned user-authorized ADB bootstrap. It must pass bytecode preservation audit; it is not a full recompilation of historic Java sources.

Signed release requires original certificate SHA-256 7f42d636e4d3c251f475eb998fbe8e92b515ded8bce3ff4d30aa90b9a738cfb1. The private JKS must not be pushed to GitHub and must be transferred through ephemeral RSA-OAEP one-shot handoff if signing occurs on Actions.

Do not claim Pixel 10/Android 17 runtime validation from host checks alone. If any build/ABI check fails, do not distribute an APK and leave the current v1.151 signed download intact.
