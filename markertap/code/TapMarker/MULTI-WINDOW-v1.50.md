# v1.50 複数ウインドウ自律

「複数アプリを開いて自律」で対象を複数選択し、分割または自由ウインドウ方式を選びます。
3画面以上は端末側の自由ウインドウ・デスクトップ表示対応が必要です。公開APIで起動位置・大きさを要求しますが、OSが無視する場合があり、このAPKだけで対応機能を追加することはできません。
全対象ウインドウの表示と重なりを確認してから自律開始します。自動配置できない場合は30秒程度配置確認を待ち、その間に手動で配置できます。その後は「表示中の対象を自律」で開始します。

増えうさぎ・農園うさぎは既定のオートマトン。他の登録アプリは保存済みオートマトンが必要です。状態・監視領域をアプリごとに読み込み、画像と中央タップをウインドウ相対座標で処理します。待機・領域中央タップ・登録アプリ復帰・停止に対応。カスタム曲線とマーカー指定のアクションはこのモードでは該当アプリを停止します。既定2ゲームの収穫連打は対応しています。

隠れたウインドウは待機し、見えると再開。移動・サイズ変更中は古い座標のタップを中止。タップはAndroidの入力を共有するため順番に送信し、画面数が増えるほど1アプリ当たりの確認周期は長くなります。

ビルド・署名確認・既存テスト・1～32画面の配置計算テスト通過。実機での自由ウインドウ起動と、サイズ変更後のゲーム画面の検出精度は未確認です。
