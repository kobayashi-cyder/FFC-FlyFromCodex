# v0.11 — 数値規則の帰納WSPと厳格な採用判定

- 学習済み外部モデルの利用なし。既存v0.10のチャット、意図分類器、回路工房、会話履歴、資料検索を維持。
- `chat_web/wsp_induction.js`: 1〜3入力の数値例からWSPグラフを合成。既知の算術・比較・非線形候補に加え、訓練例のみを使って線形結合の係数・バイアスを数値推定し、`linear`ノードの実際の重みに書き込む。
- 完全に同じ訓練入力、訓練と評価での入力重複、非有限値、過大な配列を拒否。holdoutは規則選択には使わず、採否の最終判定のみに使用。
- 訓練例から複数の異なる関数が成立する場合は、区別できる入力例を提示し採用しない。
- 合格したレポートのみ採用。転用・改ざん・二度目の採用は拒否。適用後のグラフはロールバック可能。
- `帰納WSP`パネルとチャット `/induce` コマンド追加。v0.10保存履歴をv0.11に移行。
- 100種の合成算術課題で **100/100** 成功（訓練は入力 -9〜9、評価は10〜30）。これは事前定義された関数群内の成績であり、一般的な未知問題・自然言語・Sol級知能ではありません。
- Node.js 95件、Python基礎13件のテストを実行。Chromiumは`file://`へのアクセスが管理制限されるため、HTMLを直接読み込む方法でUI操作をテストし、帰納回路の構築・適用・実行を確認。

**重要な境界:** 仮説候補にない規則は推論不能です。holdoutは人工問題の範囲外汎化であり、外部実データを用いた汎用能力の検証ではありません。大規模基盤モデルは未学習です。
