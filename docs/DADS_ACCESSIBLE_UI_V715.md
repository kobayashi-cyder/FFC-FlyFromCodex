# BANC888 v7.15 — デジタル庁デザインシステム参照・操作可能性改善

## 目的

ユーザー報告「実際の操作ができない」を優先し、四機能（会話、コード、画像、動画）をモバイル画面上部から選択でき、入力・送信・添付・音声操作が押せるようにする。

**デジタル庁公式アプリではない**。公開デザインシステムの原則を参考にしたBANC固有の実装であり、デジタル庁から審査・認証・推奨されたものではない。

## デザイン・アクセシビリティの根拠

- [デジタル庁デザインシステム](https://design.digital.go.jp/dads/)（v2.18.2、2026年10月21日更新）
- [ボタン：アクセシビリティ](https://design.digital.go.jp/dads/components/button/accessibility/)：タップ目標は44×44 CSS px以上、対比、明示ラベルと視覚フォーカス
- [ボタン：使い方](https://design.digital.go.jp/dads/components/button/usage/)：実行アクションの重要度に応じた塗り、アウトライン、テキストの使い分け
- [ボトムナビゲーション](https://design.digital.go.jp/dads/components/bottom-navigation/)：2026年9月9日時点で非推奨。ジェスチャー領域との競合を避けるため、画面上部にナビを置く
- [モバイルメニュー](https://design.digital.go.jp/dads/components/mobile-menu/usage/)：階層を浅くし、操作のラベルを明示
- [ドロワー](https://design.digital.go.jp/dads/components/drawer/usage/)：モーダル、閉じる操作、背景遮断
- [テキストエリア](https://design.digital.go.jp/dads/components/textarea/usage/)：明瞭な入力項目ラベル、入力しやすい領域
- [カラー](https://design.digital.go.jp/dads/foundations/color/)：本文コントラスト4.5:1目安、見えるフォーカス

## 修正内容

1. **四機能の選択を可視化**：画面上部に「会話」「コード」「画像」「動画」の4ボタン。押したボタンは選択状態を明示。コード/画像/動画は編集可能な依頼例を入力欄へ挿入し、送信は自動では行わない。
2. **未送信の入力を保持**：利用者が入力した原稿をモード切替で上書きしない。
3. **「↑」を「送信」に変更**：青い塗りボタン、最小48px高。アクセシブルネーム付き。
4. **添付・音声・停止を文字付きボタンに**：最低48px。見やすい一貫したアウトラインと間隔。
5. **配色・表示サイズ**：初回は高コントラストな明色テーマ、暗色テーマ設定も維持。本文16px、フォーカスは黄色+黒の二重強調（オリジナル配色）。
6. **設定と会話一覧**：モバイルは上部ラベル付きメニュー、開いたドロワーのみフォーカス可能。ESC、クローズ操作、フォーカス復帰、Tab移動を整備。
7. **状態表示**：入力・操作の状態を文字で表示し、スクリーンリーダーにも通知。
8. **safe areaとキーボード**：端末下部のジェスチャー領域・画面高さを考慮。ボトム固定ナビゲーションは使用しない。

## 実際の操作

アプリを起動 → 上部「会話」「コード」「画像」「動画」から1つ選択 → 下の依頼文を入力/編集 → 「送信」を押す。設定は右上の「設定」。既存の会話履歴は「☰ 会話」。添付、音声、停止は送信欄に隣接する実際の操作ボタン。

生成結果の能力制限はv7.14から変えていない。自由言語生成はモデル接続設定に依存し、O2画像は手続き描画。動画はO3→MP4、必要に応じてA1111を利用する。

## テスト

- Node：tests/dads_ui_contract.test.cjs — CSS設計原則、実登録、モード選択、編集中テキスト保持。
- Android：ChatControlsIntegrationTest.accessibleModesAreTouchableAndMessageCanBeSent — 実タップで4モードと送信を確認。既存設定、添付、会話操作のテストも実行。
- GitHub Actions：APKビルド、ハッシュ整合性、Android Debug署名。**Android実機Pixel 10の最終的な操作確認は端末側で別途必要**。

## ロールバック

本改修は開発ブランチと別アプリID（com.ffc.banc888.fly.accessible）を使うため、v7.14統合版は残せる。署名はDebug用。旧バージョンのデータを自動移行しないため、会話は旧アプリでJSON出力してから扱うこと。
