# MarkerTap v1.90 — ボックスマージの標準自律

パッケージ `jp.tapmarker.lite`、versionName `1.90`、versionCode `93`。v1.89からの上書き更新です。

## 開始方法

1. 旧版の「全停止」を押します。
2. `MarkerTap-v1.90-box-autonomy.apk` を上書きインストールします。
3. ユーザー補助の「マーカー連打」が有効であることを確認します。
4. ボックスマージを前面で開き、操作パネルの「自動開始」を押します。

標準設定では連打マーカーを中央付近に自動配置します。停止は「全停止」です。

以前ボックスマージを実演学習・独自編集していた場合、その設定を保持します。今回の標準自律を使うには、停止してから「かんたん編集」→「図で編集」→「初期設定へ戻す」を選びます。現在のオートマトンは退避されます。

## 追加した操作

| 録画の表示 | 自律処理 |
| --- | --- |
| 開始時のコイン還元率の告知 | 告知の見出しと右上×を確認し、×を押す |
| タイトル | ロゴと「プレイ」を確認して開始 |
| 通常プレイ | 中央付近へのキューブ投下を繰り返す |
| コインアップチャンス | 「このままはじめる」で継続 |
| 100投達成の「報酬を受け取る」 | ボタンを確認して回収処理へ進む |
| コイン獲得の画面 | 見出しと「閉じる」を確認して閉じる |
| 録画内の広告2系統 | 独立した2つの目印を新しい2枚の画像で確認し、ホーム経由で元ゲームを開く |
| 元ゲームへ戻った後 | 確認画面を処理し、通常プレイを確認してから投下を再開 |

ゲーム、告知、継続、報酬は、見出しと操作部分の両方を照合します。画像で確認した位置をタップ直前に再確認します。通常プレイの目印が消えた場合、別アプリ表示中、復帰中、画像が古い場合は連打を保留します。以前からの有限5点のランダム選択と、押下・解放を区切る入力設定を引き継ぎます。

CMのホーム復帰では、ホーム画面の表示を確認してから元ゲームを開きます。広告の目印が消えたり、ゲームの表示が戻ったりした場合は保留中の復帰を取り消します。録画と合わない広告は、既存の閉じる・戻る・登録アプリへの復帰処理を使います。ホームに移っただけで報酬獲得済みとは扱わず、実際に報酬画面が出た場合に閉じます。

## 対応範囲

録画6724の操作ループに対応します。中央への投下を繰り返す方式で、キューブの数字・配置から最適な投下方向を探索する機能は含みません。録画にないミッション一覧の一括回収や、未知のダイアログの自動操作は未対応です。

複数画面でもプリセットと画面別の認識・投下処理を使用します。早期のホーム復帰は前面の単一画面が対象です。仮想画面は既存の画面別の閉じる・戻る・復帰を使用します。

## 検証

見本作成に使った時点を除いた録画画像81枚で682項目の検証を行いました。1080×2424の原寸画像5枚を含みます。開始、告知、継続、100投報酬、報酬の閉じる、広告、Androidホーム、通知画面を含めて確認しました。目印を片方ずつ消した画像、サイズ変更、古い画像、同じ画像通知の再利用も検証します。

配布APKと同じ縮小済みJavaクラスで既存のcore回帰テストを実行します。結果は `tests-v1.90.log` と `VALIDATION-v1.90.json` に保存します。

Android実機は接続されていません。F-52A・Pixel 10での実際の入力、広告からの復帰、報酬の付与、複数画面の挙動は未検証です。
