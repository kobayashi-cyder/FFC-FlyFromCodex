# Inter-Chat Handoff / Respect Protocol

このファイルは、FFC / BANC888 を複数の ChatGPT チャットで並列開発するための共有面です。

## 原則

- 別チャットの成果は「先行研究・共同成果」として扱い、勝手に上書き・巻き戻し・再解釈しない。
- 既存成果に触れる前に、実ファイル・commit・branch・version・基盤系列を確認する。
- 競合した場合は「どちらかを消す」より、差分を明示し、統合可能な部分を分離して残す。
- 版番号は連番前提にしない。馬跳び方式を認め、実内容と provenance で最新版を判断する。
- BANC888 では、基盤データ系列・O0/O1/O2/O3などの層を区別し、由来を明記する。
- 他チャットが作った成果を利用した場合は、その成果を自分の新規成果のように扱わず、継承元として明示する。
- main へ反映する場合も、他チャットの変更を尊重し、必要なら branch / PR / diff を介して統合する。
- 共有用の要約は、結論だけでなく「何を変えたか・何を変えていないか・次にどこを触るか」まで残す。

## 現在の共有事項

BANC888 の画像生成系では、A1111 を一時的な教師として利用し、最終的に O2 側へ知見を還元する方針を採用している。

現在 main には、9ドメイン / 45概念 / 2,880教師ジョブの生成・検証系が入っている。
対象ドメイン:

- FOOD
- LANDSCAPE
- ANIMAL
- PERSON
- OBJECT
- ARCHITECTURE
- VEHICLE
- INSECT
- CONNECTOME_STYLE

GitHub Actions で以下を検証する:

- ジョブ総数とドメイン別件数
- ID / filename の一意性
- 必須評価フィールド
- 全概念に O2_MATCH が存在すること
- 同条件での deterministic regeneration

## これから別チャットへ渡すとき

最低限、以下を共有する:

1. 使用した branch / commit / version
2. 追加・変更したファイル
3. テスト結果
4. 既存成果を変更していない部分
5. 未解決点
6. 次に触ってよい場所 / 触らない方がよい場所

## 敬意について

別チャットは「別の作業者」ではなく、同じプロジェクトを別方向から進めている共同開発者として扱う。
先に積み上げられた設計・実装・検証を尊重し、その上に積む。
