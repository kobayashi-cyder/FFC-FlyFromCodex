# 会話UIとJSON保存 v7.7

v7.6/PR #8 のMP4・品質改善を継承し、会話を主画面にした。左の会話一覧、新しい会話、中央のメッセージ、下の複数行入力欄、スマホの会話一覧メニュー、ライト/ダーク表示を使える。Enterで送信、Shift+Enterで改行、日本語変換中のEnterは送信しない。既存の回路・音声・画像・動画の操作は「設定・ツール」に残す。

コードと文書は会話に生成物を表示する。画像は小さいプレビューを最大8枚/各32KiBだけ一時保持し、JSONや会話保存に画素を複製しない。再起動後は画像の生成メタデータを表示する。MP4の完成情報は該当するメッセージへ一度保存し、完成ファイルだけ共有できる。フレームごとの会話保存は行わない。

「会話JSON保存」は選択中の会話、「全会話JSON保存」は保存された会話を出力する。発言のrole/content/createdAt、会話ID、生成されたコード・文書、内部検査結果、画像の生成メタデータ、一致するjobIdのMP4ファイル情報を含む。ネイティブ認証情報、任意のメタデータ、画素・base64動画を含めない。ユーザー自身が発言した文字列は会話内容として出力する。古い会話履歴がある場合、全会話出力に別会話として含める。

JSONは `BANC888-conversations` / schemaVersion1。保存処理はUTF-8ファイルをapp cache/exportsへ書き、content:// FileProvider URIを返す。共有画面は「保存したJSONを共有」を押した時だけ開く。ブラウザーではファイルをダウンロードする。長期保存は共有先で行う。NDJSONとJSONコピーも詳細メニューに残す。

現在の会話ストレージは各会話の直近120発言を保持する。出力は通常会話最大256件と旧履歴1件、各会話120発言、内容と生成メタデータ計4Mi文字を上限とし、上限による省略はtruncatedフィールドと画面に明記する。選択中の会話は256件以降にあっても出力する。JSON単体でAPK内の画像・動画バイナリを移すことはできない。

JavaScriptの21検査、ブラウザーでの送信・改行・JSONファイル再読込・会話切替・保存復元・デスクトップ/スマホ幅を確認する。Android `ChatJsonIntegrationTest` は実際の入力欄からCSVコードを生成し、JSONをネイティブファイルへ保存して読み直す。共有の自動起動がないこと、パスとトークンの拒否も確認する。Android実行結果はPRのCIを参照。
