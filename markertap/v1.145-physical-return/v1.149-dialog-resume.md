# MarkerTap v1.149候補：開拓うさぎの「このままはじめる」と「キャンセル」

## 観測と限界（2026-11-02）

ユーザー提供の 684×1536 スクリーンショットでは「タップ２倍」「1タップで進む量が２倍！」「使用する（広告）」「キャンセル」が見える。画面中央にはMarkerTapの最小化・復帰用フロートが重なる。「このままはじめる」は過去の動画に登場した別のコインアップ画面であり、この静止画には出ていない。

**この画像は入力が出たか、ゲームが反応したかを証明しない。** 現行v1.148は `KaitakuUiEvidence.sample` 経由の文字・矩形がゲーム側から公開されなければ何も押さず保留する。

## 修正（今回実際にコミットした範囲）

- 旧判定が最初に `デイリーミッション` を見つけると無条件 `NONE` にしていたため、背景にミッションの文言が残るポップアップを取り逃がす経路を修正。固有のダイアログ判定を先に行う。
- `コインアップチャンス` の説明文がアクセシビリティツリーに存在しないケースでも、タイトルと**正確に一致する「このままはじめる」ボタンの安全な矩形**を取得できれば広告を回避する。
- 「このまま始める」の表記ゆれを吸収する。
- タップ２倍は「1タップで進む量が2倍」という説明文と「キャンセル」の矩形が必要。単なるミッション行と区別する。
- 広告付き「使用する」や「CMを見て…」は自動押下しない。ボタン座標が取れなければ安全停止（HOLD）。座標を憶測で生成しない。
- ホスト回帰に背景ミッション、説明文欠落、表記ゆれ、今回スクリーンショットの「キャンセル」縦位置を追加。

## 残る本質的な未解決点

ゲームがテキスト・ボタン位置をユーザー補助に公開せず、Canvas/Unity描画のみである場合、この改修だけでは`このままはじめる`も`キャンセル`も押せない。新鮮なスクリーンショットを入力にした視覚認識、ダイアログ種類の独立検証、座標補正、操作API結果、次フレームでの画面変化・報酬反映照合を接続する必要がある。単一画像の固定座標を無条件タップする修正はしない。

## 版・署名・配布

このブランチの変更は**v1.149に向けたソース候補**であり、APKを再構築・署名したという意味ではない。v1.148の署名済みAPKにこの改修は入っていない。APKの生成時はManifest versionCodeとDEX版表記も更新し、元の証明書一致、署名、ZIP整合性を検査すること。現時点ではGitHub Releaseにこの変更を含む署名APKは存在しないため、READMEに架空のダウンロードURLを記載しない。パスワードや元鍵を公開Gitに置かない。
