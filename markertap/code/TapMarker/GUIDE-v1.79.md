# MarkerTap v1.79 — ポット増加の確認画面をキャンセル

パッケージ `jp.tapmarker.lite` / versionName `1.79` / versionCode `82`。
`MarkerTap-v1.79-coin-cancel.apk` を上書きインストールしてください。v1.78と署名・パッケージを維持しており、アプリの削除は不要です。

## 修正した停止

添付されたコイン落としの「ポットの数が増えるよ」「CMをみてゲット」「キャンセル」画面が対象です。旧版では通常画面が消えたことを検出して連打を保留できましたが、このポット数増加の確認画面を識別してキャンセルする分岐がありませんでした。旧版の再現結果は `coin-cancel-v1.78-baseline.log` に記録しています。

新しい処理は次の順序です。

1. 説明文とキャンセルの右側の文字を、新しい画像2枚で確認します。
2. 通常連打を保留し、確認できたキャンセル文字の位置へ60msの単発入力を送ります。
3. 入力の送信完了後は、確認画面が閉じるのを待ちます。
4. 確認画面の消失と通常プレイ画面をそれぞれ確認してから通常連打へ戻ります。
5. 確認画面が残っている場合は、1.5秒後に画面を再判定します。古い位置を連打しません。

今回の画像では中央のマーカーがキャンセルの文字に重なっています。認識・入力には右側の見えている文字を使います。操作パネルで隠れている上部の見出しを必須にしません。実行時は画像内の表示位置に合わせて補正します。説明文またはキャンセル文字が読めない場合は、その位置への入力を許可しません。

## 引き継ぎと操作

上書き後、対象ゲームを開いて「自動開始」を押してください。ユーザー補助が停止した場合は、Android設定で「マーカー連打 軽量版」をOFF→ONにします。

未編集の標準オートマトンは新しい分岐へ自動更新します。変更前の設定をバックアップし、同じ更新を繰り返しても分岐を重複追加しません。独自編集・録画から生成した設定は自動上書きしません。

通常連打・スコップ強化・増える量の分離はv1.78を引き継ぎます。通常プレイでは最速連打を継続し、今回のような別の確認画面では保留します。最速指定の実効速度は端末とゲームによります。

## 検証範囲

`CoinCancelScreenshotTest` は、提供された1枚の画像と、合成した縮尺・余白・文字欠落・時系列を使った200項目を検査します。画像の認識、マーカー外のキャンセル座標、CMボタンとの区別、古い入力位置の拒否、画面消失前の連打禁止、再試行、確認後の再開、旧標準設定からの移行を含みます。

既存録画の主画面・広告・タップ2倍・ミッション・読み込み中の画像に対し、今回のポット数増加画面と誤認しないことも確認します。旧録画の学習・評価用フィクスチャは変更していません。

配布APKと同じ縮小済みJavaランタイムで `run-tests.sh` のcore検査を実行し、APKのv2/v3署名、旧版との署名一致、versionName/versionCode、DEX・アセット一致、4種類のCPU向けライブラリ、16KB配置を検査します。

**F-52Aへの実入力と、ゲーム側で実際にキャンセルが成立することは、この環境では未検証です。** 1枚の画像から全端末・全種類の確認画面への対応を保証するものではありません。旧4録画のfull検査には別途フィクスチャが必要です。

検証記録：`coin-cancel-v1.79.log`、`tests-v1.79.log`、`VALIDATION-v1.79.json`、`apk-verification-v1.79.log`。
