# MarkerTap v1.88 — 録画6720のコイン落とし自律化

パッケージ：`jp.tapmarker.lite`。versionName `1.88`、versionCode `91`。v1.87を土台とし、従来と同じ証明書で上書き更新できます。

## 修正内容

- 操作パネルに隠れていない説明文と図柄から、レアコイン強化とポケット強化を区別します。種類を確認できた画面で、別の強化画面の弱い一致が同時に成立して停止する問題を防ぎます。複数の種類を確実に区別できない場合は入力を保留します。
- フィーバーは、パネルの左側に見える文字とBANK表示の2領域で確認します。クリア演出は、落下中のコインに依存せず、クリア文字と袋の図柄で確認します。
- デイリーミッションの見出し、未回収の「ゲット」、回収後の「プレイ」を今回の表示に対応させました。クリア後の回収意図を広告や画面切替をまたいで保持します。
- 「このままはじめる」は、中央マーカーから離れた右側の文字を押します。CMボタンを押して開始する操作は追加していません。
- 判定の例外が発生した場合は、例外の種類と状態名を遷移ログへ記録し、Androidログへスタック情報を記録します。連打を保留して再取得する挙動は維持します。

通常プレイとフィーバーでは連打を継続し、広告・報酬・確認画面・アプリ切替では保留します。強化の任意CMは開始しません。ゲーム側の強制広告は終了印を確認して閉じ、ゲームの表示を再確認して再開します。ゲーム側の広告そのものを消す変更ではありません。

## 更新と開始

1. 旧版の「全停止」を押します。
2. `MarkerTap-v1.88-coin-autonomy.apk` を上書きインストールします。アンインストールは不要です。
3. ユーザー補助が有効であることを確認し、コイン落としを開きます。
4. 操作パネルの「自動開始」を押します。

パネルはタイトルをドラッグして移動できます。画面認識が使う文字をパネルで覆わない位置にすると観察しやすくなります。

標準設定の認識と操作位置を更新します。ユーザーが編集した領域・画像・操作・しきい値には、新しい標準設定の判定を強制適用しません。既存のランダムな離散タップ、他ゲームの設定、仮想画面とPC連携の仕組みは引き継いでいます。PC版の配布物は今回更新していません。

## 検証範囲

- 録画6720の学習に使わない47枚で192項目が成功しました。通常画面、レアコイン・ポケット強化、フィーバー、クリア、開始、ミッションのゲット、報酬の閉じる、プレイ、通常画面復帰までを確認しました。
- 暗転・広告・カウントダウン・欠けた目印・古い画像サイズ・入力直前の画面切替で、ゲーム操作を実行しないことを確認しました。
- 配布APKと同じ縮小済みJavaクラスを使う既存の `run-tests.sh` coreグループが成功しました。過去録画、状態機械、タップ、取り消し、仮想画面、ADB暗号の検証を含みます。
- APKの署名v2/v3、既存証明書との一致、4ABI、16KiB zipalign、アセットと実行コードの一致を確認しました。

この環境にAndroid実機は接続されていません。新APKの実タップやゲーム内の反応は未確認です。録画に出る「領域判定失敗」は例外の種類やスタックを含まないため、直接原因まで特定・解消したとは扱っていません。今回の改修は、録画で再現した画面の誤判定と入力位置を補強したものです。
