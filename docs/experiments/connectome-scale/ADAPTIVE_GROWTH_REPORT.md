# 自動増殖・削減・再学習の試験

10種類の滑らかな計算課題を対象に、同じ個体の学習を継続し、検証誤差の改善が鈍ると計算単位を複製した。活動への寄与が小さい単位の削減も試し、再学習後に検証精度が悪化した候補は元に戻した。

学習入力81点、判断用入力61点、最終評価入力151点を分けた。各方式の予算は16,000単位・更新とし、不採用の候補を試すコストも含めた。これは概算計算予算であり、同じ時間・電力の測定ではない。

|方式|平均評価MSE|最終単位数（平均）|
|---|---:|---:|
|自動増殖・削減|0.345229|4.5|
|小さい固定回路|0.306179|4|
|大きい固定回路|0.388255|32|

自動方式では増殖4件、削減8件が採用された。しかし、小さい固定回路に対し平均誤差は約13％大きかった。増殖・削減を自動で実行できたことと、それが有利であることは別である。

増殖判断、候補作成、再学習、不採用時の復帰、予算管理、独立入力での評価は試験できた。一方、故障耐性、複数課題への専任化、BANCの元の回路、Android端末、自由会話はこの試験に含まない。生物の発達法則の検証でもない。

学習率や成長・削減条件の最適化は未実施で、この結果から自動増殖が一般に無効とは断定できない。現時点では、自動方式の優位性を確認済みとは扱わない。
