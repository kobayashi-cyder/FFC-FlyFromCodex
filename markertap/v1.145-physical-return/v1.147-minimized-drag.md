# MarkerTap v1.147 — 最小化ボタンのドラッグ移動

**実装**：最小化した「MarkerTapに戻す」ボタンが固定位置に張り付かず、画面内でドラッグ可能に。タップで直前の拡張表示（フロートまたは画面下部固定）へ復帰します。

- `MINIMIZED=2` を独立のフロート状態として扱い、`minimizedX/minimizedY` を `panelUi` に保存。展開フロートの `x/y` を保持します。
- ボタンの `MotionEvent.ACTION_DOWN/MOVE/UP/CANCEL` を監視。`ViewConfiguration.getScaledTouchSlop()` より小さい動きはタップとし、`performClick()` によって復元。大きい動きは `WindowManager.updateViewLayout` で移動し、離した時に座標を永続化します。
- 画面外へ出ないように位置を補正。画面サイズ変更時も保存位置を補正します。
- 固定バーは引き続き動かない。自律処理の状態・入力処理・停止操作に変更なし。
