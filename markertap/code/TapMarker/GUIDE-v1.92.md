# MarkerTap v1.92 — タップ2倍を「使用しない」で閉じる

パッケージ `jp.tapmarker.lite`、versionName `1.92`、versionCode `95`。v1.91の後継です。

## 更新と開始

1. 旧版で「全停止」を押します。
2. `MarkerTap-v1.92-poipoi-decline.apk` を上書きインストールします。
3. ユーザー補助の「マーカー連打」が有効なことを確認します。
4. ポイポイうさぎを開き、操作パネルの「自動開始」を押します。

v1.91の標準オートマトンは、元の設定を退避してから今回の処理を自動追加します。標準設定のままであれば初期化は不要です。独自に学習・編集した設定は保持します。独自設定から新しい標準処理へ切り替える場合は、停止後に「かんたん編集」→「図で編集」→「初期設定へ戻す」を選びます。切り替え前の設定は退避されます。

## 今回の修正

ポイポイうさぎの「タップ2倍」確認画面で、下段の **「使用しない」** を選びます。黄色い広告付き「使用する」は選びません。

いただいた画像6727では、見出しと説明に操作パネルが重なっています。パネルの下に見えるにんじんの画像と「使用しない」の文字を組み合わせて判定します。両方を確認できる場合に限り、現在の画像から求めた文字の中央を1回押します。押す直前にも同じ2か所を再確認します。

確認画面が出ている間は通常の連打を保留します。タップ後はダイアログの消失を確認し、通常プレイの表示を確認してから連打を再開します。閉じなければ1.5秒以上待ち、画像を再確認してから再試行します。ミッション回収の途中なら、回収を続ける状態へ戻ります。

| 表示・状況 | 動作 |
| --- | --- |
| タップ2倍の確認 | 下段の「使用しない」 |
| 通常プレイ | にんじん付近へのタップ |
| オフラインボーナス | 通常の「獲得」 |
| 満足度100.00%・ミッション通知 | ミッションを開く |
| 達成済みミッション | 表示中の「ゲット」だけを回収 |
| 表示中にゲットがない | 左上の戻る |
| コイン獲得 | 「閉じる」 |
| コインアップチャンス | 「このままはじめる」 |
| 録画で確認したCM | 広告表示を確認してホーム経由で復帰 |

任意の広告操作、黄色い未達成「プレイ」、オートタップ・キャラクターチェンジの広告は開始しません。今回の確認画面以外の、未撮影の確認画面への操作は追加していません。

## 検証と制限

画像6727の原寸データと、サイズ変更・ウインドウ配置・目印を隠す加工による検証を行っています。判定、下段へのタップ位置、操作直前の画面変更、待機と再試行、ミッション回収の状態維持、旧標準設定の更新、独自設定の保持を含む386項目が対象です。画像6727は見本と再現テストで共用しており、別の実画面での独立検証ではありません。

前回の録画6725の137枚も新しい判定と照合し、確認画面の誤検出を調べています。配布APKと同じ縮小済みJavaクラスでcore回帰テストを実行し、結果を `tests-v1.92.log` と `VALIDATION-v1.92.json` に記録します。従来の4種類のCPU向け構成（arm64-v8a、armeabi-v7a、x86、x86_64）と更新用署名を維持します。

Android実機は接続されていません。実機へのタップ送信と、実際に「使用しない」を押した後のゲーム表示は未確認です。閉じた後の復帰テストには、既存録画の通常プレイ画像を使用しています。自動スクロール、デイリー全件完了の自動判定、未撮影の確認画面は引き続き対象外です。

## ソースからの画像見本の再生成

`tests/prepare-video6725.py` に録画6725を渡して従来の見本を生成した後、`tests/prepare-image6727.py` に画像6727を渡します。後者が今回の見本を追加し、APK用JSONと現在のテスト用見本を同じ内容で作成します。
