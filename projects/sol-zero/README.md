# Sol-Zero v0.10 — スクラッチ学習したオフラインChat

**Qwen / Llama / Gemma / GPT の既存学習済み重みは一切使用しません。**

- `SolZero_Chat_Offline.html` — Android / PCのブラウザで開く1ファイル版。通常のチャット・WSP回路工房・履歴・資料検索を維持。
- `/learner` — 今回学習した分類器の情報を表示。
- `/intent 資料を検索してください` — 数値重みで「計算・記憶・タスク・検索・WSP・会話」の6種を分類。**動作の候補提示のみ**。実行はしません。
- `chat_web/` — モジュール化されたブラウザ実装。
- `training/train_intent.py` — 独自生成データを使い、CPU上で乱数初期化から学習。外部教師・蒸留・モデルダウンロードなし。
- `artifacts/intent_weights_v010.json` — 24,582個の学習済み重み・バイアスをint8へ圧縮した本物のモデルファイル。
- `artifacts/intent_training_report_v010.json` — 学習前後の正答率、loss、独立評価結果。
- `scripts/build_standalone.py` — 単一HTMLを再生成。
- `tests/learned_router.test.mjs` — ブラウザ向け量子化済み推論の機能テスト。

## 実行

オフライン画面は `SolZero_Chat_Offline.html` を開くだけです。ブラウザによって`file://` での保存に制限があるため、必要に応じて端末でバックアップJSONを書き出してください。

学習の再実行：

```bash
pip install torch pytest
python training/train_intent.py --epochs 32
node --test tests/*.test.mjs
python -m pytest -q tests/test_solzero.py tests/test_weight_store.py
python scripts/build_standalone.py
```

`--epochs`を変えると結果も変わります。`seed=20261106`に固定し、同じ環境で再現可能な実験です。小さなテキスト分類器のみであり、自由会話を学習したLLMではありません。

手書きテンプレート群の6分類だけを評価した値であり、未知の自由文章・数学・一般推論での成績を示すものではありません。正答率は知能の達成率ではありません。

## 5 GB制約

完成物の**配布・保存容量を5,000,000,000バイト以下**にする設計です。実行時RAMや学習時メモリ、将来の事前学習に必要なデータ・GPUコストは別枠です。モデル重みを増やすだけでは汎用知能は実現しません。

## 次の段階

大規模言語モデルの継続学習ではなく、まず未使用入力への分類・計画、回路の性能回帰、一般化テストを拡張します。十分なデータと計算資源を確保してから1M→100M→数十億パラメータの基盤へ段階的に移ります。今回の成果に28億パラメータの学習済みモデルは含まれません。

ソースと学習データ生成式から結果を再計算できます。評価セットを学習へ流用しません。
