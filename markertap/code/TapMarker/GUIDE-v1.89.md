# MarkerTap v1.89 — CMからホーム経由で元ゲームへ復帰

パッケージ `jp.tapmarker.lite`、versionName `1.89`、versionCode `92`。v1.88の後継です。

## 変更した動作

- コイン落としで、録画6722にある広告のフィードバック印と「広告」の文字を両方確認します。新しい画像2枚、300ms以上の間隔で一致した場合、ホームを経由して元ゲームへ復帰します。カウントダウンや広告のプレイボタンは押しません。
- ゲームや確認画面が認識できた場合は、その画面の操作を優先します。目印が操作直前に消えた場合、予定していたホーム操作を取り消して再判定します。
- HOME送信後は、端末に設定されたホームアプリが前面に表示されたことを確認してから、登録済みの元ゲームを開きます。300ms以上待ち、1.5秒でホームを確認できなければ監視へ戻ります。
- 前面の単一画面を復帰させる処理からChrome経由の起動を除きました。すでにホームや外部アプリへ移っていた場合は、登録したゲームへ直接復帰します。
- 復帰中は連打を保留します。アプリ名が戻っただけで再開せず、鮮明なゲーム表示の一致を確認します。画面切替前に取得した画像や、全停止前に予約した復帰処理は破棄します。
- 任意の強化CMは開始せず、キャンセル／戻るで閉じる既存の動作を引き継ぎます。今回の2つの目印を確認できない広告は、既存の閉じる・戻る・登録アプリへの復帰処理で扱います。

今回の早期HOME判定の対象は、録画と同じコイン落としの前面画面です。未知の広告全般を判別できることまでは確認していません。

## 更新と開始

1. 旧版で「全停止」を押します。
2. `MarkerTap-v1.89-cm-home.apk` を上書きインストールします。
3. ユーザー補助を確認し、コイン落としを開いて「自動開始」を押します。

従来版と同じ署名のため、アンインストールせず更新できます。停止は「全停止」です。

## 検証

録画6722は416項目、HOME待機は14項目が成功し、既存のcore検証も終了コード0で完了しました。

- 録画6722は、見本作成に使った1.0秒・61.0秒を除く55枚を使用しました。CM、強化確認、報酬、クリア、ミッション、ホーム、Chrome、復帰時のアニメーション、通常ゲームを含みます。
- CMの2目印、片方を欠いた画像、画像サイズ変更、古い画像、同じ画像通知の再利用、復帰中の連打禁止、鮮明なゲーム表示2回での復帰を検証します。
- 実際の復帰処理が使用するHOME待機クラスを、仮想時計と模擬ホストで検証します。HOME拒否、ホーム未表示、停止、状態変更、別の実行との独立性を含みます。
- 配布APKと同じ縮小済みJavaクラスで `run-tests.sh` を実行します。既存の録画、状態機械、入力、仮想画面、キャンセル、ADB暗号の回帰検証を含みます。実行結果は `tests-v1.89.log` と `VALIDATION-v1.89.json` に記録します。

Android実機はこの作業環境に接続されていません。HOMEからゲームに戻った際にゲーム側が広告を閉じるか、実際の連打が届くかは実機での確認が必要です。ホームに戻っただけで広告終了や報酬獲得が成立したとは扱いません。
