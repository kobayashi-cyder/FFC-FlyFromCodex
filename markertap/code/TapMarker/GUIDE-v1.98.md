# MarkerTap v1.98 — 録画6743: 農園の広告表示失敗ダイアログ復帰

本改修は **v1.97のソースを基準**にした、農園うさぎの表示失敗対応です。二系統の仮想画面レーン、既存のポイポイうさぎの広告監視ロジックは維持しました。

## 6743.mp4 の観測

- 約112秒、仮想2画面。左は農園うさぎ、右はポイポイうさぎ。
- 左画面で「コインゲット! +100」→「広告を表示できませんでした」の画面に遷移後、OKを押さず後半まで残存。自律状態は収穫/フィーバーと表示したまま。
- 右画面はCM・ゲーム・Google Playの画面を行き来する。動画だけでは右側が**常に**異常であるとは断定できないため、右の終了操作の新規座標推定・Play画面の自動操作は追加していない。

## v1.98 変更点

1. 画像画素の色配置・ダイアログ形状・確認ボタン形状から農園の広告表示失敗を検出。動画中の「コインゲット! +100」を誤認しないよう、ダイアログ本文の高密度な数値表示は除外。
2. アクセシビリティでタイトル「広告を表示できませんでした」と一意な「OK」ボタンが**同じ農園ゲームウインドウ上で確認できる場合のみ**、その位置も利用。
3. 発見したレーンの収穫連打とBANC側の保留操作を停止、2枚以上・140ms以上の独立した新フレームで確認したOKだけを一回押下。
4. タップ送信の事実だけで回復したとは認定せず、画面上からダイアログが消えたことを連続画像で確認後に農園の `check` 状態へ戻す。
5. 同一表示への再試行は2.7秒以上空け、最大3回。3回後も閉じなければ農園レーンだけ止め、手動確認を表示する。もう一方は継続可能。
6. 単画面のAutoPilotにも同じゲートを適用。標準プリセットのみで発動し、ユーザーが編集した独自の操作グラフには割り込まない。

## オフライン検証

`6743.mp4` 由来の9枚を使い、ピクセル検出と状態ゲート計34項目をJava 17上で確認済み（`tests/FarmAdErrorRecoveryTest.java`）。そのうち4枚の通常/報酬/空白画面は不一致、5枚の表示失敗画面は一致しました。**端末での表示認識・入力実行・実際のCM完了については未検証です。**

## ビルド

必要条件：Android SDK API35、Build Tools 35.0.0、Java 17、既存のv1.97と同じ署名鍵（ユーザー保有・別管理）。

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
export TAPMARKER_KEYSTORE=/path/to/your/lite-development.jks
bash build.sh
bash run-tests.sh
```

v1.98の `android:versionCode=101`、`versionName=1.98` です。同一証明書で署名した場合は上書き更新できます。署名鍵は本パッチ・ソースには含めません。

*注意*：この環境にAndroid SDKと実機がないため、v1.98の署名済みAPKは生成していません。パッチZIPからAPKが直接インストールできるわけではありません。再ビルド・実機動作試験が必要です。
