# MarkerTap v1.96：CM後の自律復帰を修正

**元の署名鍵をv1.92ソースから復旧し、従来APKとの証明書一致を確認した署名済み更新版です。端末でのCM後の停止解消は未確認です。**

パッケージ`jp.tapmarker.lite`、versionName`1.96`、versionCode`99`。v1.95のコインボタン認識・ポイポイの認識と入力時間の改善を含みます。

## 確認した停止経路と修正

| 経路 | v1.95で確認できた問題 | v1.96の修正 |
| --- | --- | --- |
| 閉じるを再試行しても画面が進まない | 観測ループでは再試行済みの閉じるを無効化する一方、アプリへ復帰する直前には無効化せずに再撮影を判定していました。閉じるが描画されているだけで復帰要求を取り消し、再び同じ待機へ戻ります。 | 復帰直前にも、同じ再試行回数・待機間隔の判定を適用します。使い切った閉じるが表示され続けても復帰要求を取り消しません。新しく試せる終了印やゲーム画面は引き続き優先します。 |
| 報酬回収やミッションの途中にCMが出る | 不明画面が続いた際のCM割込み検知が、増えうさぎに限定されていました。 | 標準対応6ゲームへ共通化しました。新しい画像を3回以上、2.5秒以上観測しても現在の表示を確認できない場合、CM終了とゲーム復帰の監視へ移ります。これだけで未確認の座標をタップすることはありません。 |
| 動画CM・プレイアブル・終了カードが続く | 同じ位置に現れる閉じるの再試行回数が、次のカードにも引き継がれていました。 | 2枚以上の新しい画像で300ms以上、閉じるの消失を確認してから再出現した場合は、次の表示として再確認します。CM全体での入力上限8回は維持します。 |

ミッション回収中のCMは回収経路へ戻します。明示的な停止、編集済み・学習済みのワークフロー、アカウント等の保護画面の扱いは変更していません。通常連打に実行時間の上限は追加していません。CM中は通常連打を保留します。

## 検証

- v1.95の実行コードで、使い切った閉じるが復帰要求を取り消すこと、次のカードの同位置の閉じるを無効扱いすること、コイン・ポイポイの回収待ち中のCM割込みを検知しないことを再現しました。`ad-continuation-baseline-v1.95.log`に記録しています。
- 新規`AdContinuationTest`は481項目に合格しました。対応6ゲームの割込み、古い・重複した画像の拒否、画面ごとの独立、入力上限、復帰直前の再試行判定を確認しています。
- ポイポイの既存録画の画像を使用し、「満腹→ミッション→ゲット→CM→閉じる→第2のCM→閉じる→報酬→ミッションから戻る→連打可能」の流れを3周検証しました。入力完了と終了印は模擬した時系列であり、実際のCMや端末を操作した結果ではありません。
- 従来の検証を含む102組のJava回帰、模擬ADB8シナリオ、Androidビルド、APKの内容と16KB配置を確認しています。実行ログは`tests-v1.96.log`、詳細は`VALIDATION-v1.96.json`です。

今回止まったCMの新しい録画・停止時の遷移ログは提供されていないため、その実機での直接の原因が上記のどれかは確定していません。未知の広告すべてへの対応や端末上の成功率を示す検証ではありません。

## 更新方法と署名

1. 旧版の「全停止」を押します。
2. `MarkerTap-v1.96-ad-recovery.apk`を上書きインストールします。
3. ユーザー補助を確認し、対象ゲームで「自動開始」を押します。仮想画面・PC表示は更新後に接続し直してください。

パッケージと署名はv1.94と同じで、versionCodeは97から99に上がります。通常の上書き更新では既存の設定を引き継ぎます。署名方式v2/v3、16KB配置、APK内の全ペイロードが検証済みの署名前APKと一致することを確認しました。

署名鍵は`MarkerTap-lite-signing-backup.zip`として別に保存しました。ZIP内の`lite-development.jks`と`README.md`を保管してください。ソースZIPには秘密鍵を含めていません。元の証明書SHA-256は次です。

```text
7f42d636e4d3c251f475eb998fbe8e92b515ded8bce3ff4d30aa90b9a738cfb1
```

Java17・Android API35・Build Tools35.0.0で、バックアップの鍵を指定して署名できます。

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/lite-development.jks \
bash sign-release.sh
```

`release/MarkerTap-v1.96-unsigned.apk`は再署名用の中間ファイルです。署名後は従来証明書との一致を確認し、不一致なら最終APKの出力を中止します。全ソースの再ビルドは`build.sh`、回帰検証は`run-tests.sh`です。検証記録は`VALIDATION-v1.96.json`、鍵の回収記録は`SIGNING-RECOVERY-v1.96.json`です。実機での更新・CM後の継続動作は未確認です。
