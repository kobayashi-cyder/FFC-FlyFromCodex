# MarkerTap v1.107：新しい処理回路・正規化の実装結果

処理の接続を新規に定義して実行するAPKを作成しました。既存BANCの抽出は行っていません。解析用画像を共有する8ノードの回路と、画面適応後のオートマトンの画像見本の正規化を実装しています。増えうさぎのゲット対応と、パネル内の見出しプルダウンも含みます。

## 画像バッファの比較

同じ録画画素を旧保持方式と新回路へ入力し、実際に確保したJava配列をOpenJDKのInstrumentationで測定しました。2つの仮想画面が同じ解像度の場合です。

| 各画面の解像度 | 解析用配列の合計：従来 → 新回路 | 削減 | 元画像も含む該当配列の合計 |
|---|---:|---:|---:|
| 540×1212 | 5,235,872 → 2,617,936 bytes | 2.50 MiB | 10,471,744 → 7,853,808 bytes |
| 720×1616 | 9,308,192 → 4,654,096 bytes | 4.44 MiB | 18,616,384 → 13,962,288 bytes |

解析用配列は2つから1つへ半減し、元画像を含む該当4配列は3配列へ減りました。この配列部分の25%削減です。画面取得の元画像やゲーム本体を削除した値ではありません。新しい回路とキューの小さなオブジェクトは、この画像配列の内訳には含みません。

## オートマトンの正規化

通常画像・補助画像・通常画面用の代替画像・複数の組合せ見本を、値が完全に一致するときに共有します。アプリごとの共有プールを使い、保存設定・別アプリの実行モデルから分離します。実行時には状態やルールのID、並び順、履歴、確認回数、待ち時間を維持します。

| 初期モデル | 正規化前 | 正規化後 | 差 |
|---|---:|---:|---:|
| 増えうさぎ | 632,096 bytes | 381,928 bytes | −250,168 bytes |
| 農園うさぎ | 314,312 bytes | 267,848 bytes | −46,464 bytes |

エンジン・レイアウト・強化処理の個別測定の合計では、946,408 → 649,776 bytes、約0.28 MiBの削減です。共有オブジェクトをアプリ間で二重に数える場合があるため、プロセス全体の減少量とはしません。観測前の初期モデルの測定で、学習済みデータや解析中の一時配列は含みません。

構造の正規化についても、代替見本・計算方法・制御表示の条件が違うものは統合しない比較へ修正しました。箱・ポイポイも、操作制御からIDで参照されるプリセットを保護します。通常の重複状態・ルールの整理は既存の保存時の経路で行い、実行時には生きた状態IDを消しません。

## 動作と処理時間

録画6759のゲット、6753のプレイ、6645の主画面・報酬・広告を使った13場面を、2解像度に拡大縮小して比較しました。各解像度で2周の準備後、5周を計測し、実行順を交互に入れ替えます。計測した130組すべてで特徴量のfloat値、選択したルール、タップ座標、主画面判定が一致しました。130組とも空の判定ではありません。

| 解像度 | 旧保持方式の中央値 | 新回路・正規化後の中央値 |
|---|---:|---:|
| 540×1212 | 5.9519 ms | 5.6629 ms |
| 720×1616 | 5.6732 ms | 5.8877 ms |

これはホスト上で順に実行した1回の比較です。速度向上を結論づける値ではなく、2ワーカーによる従来方式の同時処理能力も計測していません。新方式では重い解析の同時実行数を1つへ制限します。画面取得・入力・プレビューは引き続き非同期で動きます。

回帰はcore群109本、追加Java検査6本、模擬ADB8件が成功しました。新回路の寿命・取消し・例外・並行呼出しは26項目、正規化は225項目、今回のゲット修正は646項目を確認しています。ロケール検査は3,184項目、627表示文言です。過去full群4本は復元元に録画fixtureがないため未実行です。

## 回路の範囲

要求と時刻を確認し、元画像を共有バッファへ複製して既存の画像認識を実行します。実行要求を再確認して結果だけをUIへ渡し、画素参照を解放します。停止・画面の作り直し・古い画像・例外では取消しと解放へ進みます。画素は解析中だけ有効で、古い非同期結果から別画面へ入力しないよう、世代と画面IDを再確認します。

これは処理を実行する新しいソフトウェアの接続グラフです。画像認識・意思決定の各関数を全て神経回路へ置換したものではありません。

**Android実機は接続していません。実機PSS、ピークRAM、ゲーム・GPU・native側のメモリ、追加UIの実機操作、入力配送、報酬加算、長時間運転は未確認です。同時アプリ上限は2のままです。**

## 更新方法と再現資料

旧版で全停止して仮想画面を閉じ、`MarkerTap-v1.107-frame-circuit.apk` を上書きインストールして画面を作り直します。同じ署名鍵の更新APKです。

ソースZIPに `GUIDE-v1.107.md`、比較テスト、`FRAME-CIRCUIT-BENCHMARK-v1.107.json`、`normalization-memory-v1.107.json`、各ログ、`VALIDATION-v1.107.json`、変更差分 `changes-v1.107.patch` を同梱します。再測定手順はガイドにあります。署名鍵は含めません。
