# MarkerTap v1.134 検証候補

package `jp.tapmarker.lite`、versionCode 137。元の署名を維持し、表示解像度・密度・認識しきい値は変更しない。

修正した経路:

1. 画像取得後1500msという既存の期限を、解析中・計算終了時・結果配送時にも確認する。古い結果は既存の再取得経路へ返す。ブロックしたネイティブ呼び出しの強制中断は保証しない。
2. 重複画像の早期returnでもCaptureCircuitの処理枠を解放する。後着コールバックは新しい枠を解放できない。
3. メモリ解放は未使用なら即時、使用中なら解析終了時に行う。共有解析プールへロック待ちの解放処理を追加しない。
4. タイマーに残った主画面フラグで認識障害を解除しない。時刻が新しく期限内の認識成功だけで異常を解除する。

追加回帰試験は38項目（16+13+9）。修正前の実コードでは期限と監視の試験が失敗し、修正後は通過した。既存の回帰試験、障害8件の認識ダイジェスト、DEX参照、診断保存のロック、実APK内の修正、署名、バージョン、16KB配置を検証する。

`restore_project.py` はSHA-256で原本を検証し、v1.132→v1.133→今回の修正を再構成する。生成した主要3クラスはレビュー用のoverlayと完全一致しなければ停止する。ソース置換のアンカーが変わっていても停止する。

Android API 35、build-tools 35.0.0、JDK 17、JADX 1.5.3の検証済みjarを用意し、`build_ci.py --sdk PATH --jadx JAR` を実行する。既存鍵はローカルの `TAPMARKER_KEYSTORE` で指定する。指定がなければ未署名APKになる。署名鍵はソースや成果物に含めない。

Pixel 10での起動・広告復帰・接続断・日次完遂・報酬加算・3日間の無人稼働は未検証。「完全自律化」「不具合ゼロ」とは判定しない。CIFA part3のホスト67件は通過したが、MarkerTapへの統合や未知画面からの自律学習を今回実証したものではない。
