# MarkerTap v1.63

動画6666.mp4の「買い物うさぎ」に専用のオートマトンを追加しました。増えうさぎ・農園うさぎ・うさぎのコイン落としと、アプリごとの編集・学習機能も含む更新版です。

## 更新と開始

1. 旧版で「全停止」を押します。仮想ウインドウは閉じてください。
2. MarkerTap-v1.63-shopping-video.apk を上書きインストールします。アンインストールは不要です。
3. 買い物うさぎを開き、パネルの「自動開始」を押します。初回は状態・矢印・領域と、倉庫の「運ぶ」用マーカーを自動作成します。
4. 既に買い物うさぎ用のオートマトンを自分で編集している場合、その内容を保持します。今回の初期設定を使うには、編集画面の「初期設定へ戻す」を選択します。既存の内容を退避してから置き換えます。
5. 複数の仮想ウインドウでは、「複数アプリを開いて自律」で買い物うさぎを含めて選択してください。更新後は端末内接続を接続し直し、ウインドウを開き直して「自動開始」を押します。

## 買い物うさぎの処理

| 確認した画面・表示 | 操作と次の処理 |
| --- | --- |
| 売り場の「商品入荷」と空き棚 | 表示された棚を個別に確認して、その棚の中央をタップ |
| 品出し | お肉300を選択。お肉のボタンが一致しない場合は、確認できたにんじん15を選択 |
| 売り場の来店うさぎ | 動画で確認できた来店うさぎの顔を個別に確認して回収 |
| 来店の獲得表示 | 「コインをもらう」があるときだけ押す。自動で消える表示は消えるまで待つ |
| 補充・回収後の売り場 | 「バイトする」を押して、倉庫の表示を確認 |
| 倉庫の「運ぶ」 | このウインドウで補正した位置を連打 |
| 倉庫の「タップ2倍」 | 有効なタイマーが見つからず、ボタンを確認できた場合に開く。確認画面の「はい」を押して広告終了を待つ |
| 深夜シフト・うさぎを呼ぶの確認画面 | それぞれの画面にある予約・「はい」を押して広告終了を待つ |
| 倉庫クリア・ミッションの通知 | 連打を保留してミッションへ進む |
| ミッションの「ゲット」 | 表示中の未回収ボタンを上から個別に確認し、そのボタン自身の中央を押す |
| 報酬広告・コイン獲得 | 広告終了を待ち、「閉じる」でミッション確認へ戻る |
| ミッションの「プレイ」 | 未回収の「ゲット」が検出されない場合に押す。倉庫の復帰を確認してから連打再開 |
| 広告の終了表示 | 広告状態の上隅だけで、白い×・白い二重矢印を確認してタップ。数字のカウントダウンは押さない |
| 外部アプリへ移動 | 登録したゲームへ復帰。ミッション途中ならミッションの処理を続ける |

27状態で、売り場・倉庫・品出し・来店獲得・強化広告・ミッション広告・復帰確認を区別します。品出しはゲーム内のお金を消費します。にんじん・りんご・ミルク・お魚・お肉の各行も個別の領域として用意しています。

来店うさぎは動画で確認した3種類と3位置が初期設定の対象です。深夜シフトとうさぎを呼ぶ処理は、確認画面が表示された場合の対応です。運ぶ量・運ぶ速さの購入、売り場拡張、動画にない来店うさぎや配置は初期設定では自動実行しません。必要ならアプリごとの編集・観察学習で追加できます。

## 表示位置と同じ画面の判定

各画面の見出しや固定文字と、操作ボタンの文字を組み合わせて確認します。数値・タイマー・動く紙幣を主画面の一致条件に含めません。品出しの縮小表示にも専用の見本を追加しました。

ウインドウごとに状態と座標を持ちます。操作の直前にも表示を確認し、画面が変わった場合はタップと遷移を取り消して再確認します。通常表示・仮想表示の余白や拡大縮小に合わせて座標を補正します。表示用の小窓の座標を入力先には使いません。

画素の解析は現在の状態に必要な小さな目印に限定します。空き棚・来店うさぎは登録した位置の候補、ミッション報酬は表示中のボタン列の細い縦線と文字、広告は上隅を確認します。画像取得自体はAndroidが提供する対象画面のキャプチャです。

デフォルト間隔は3msです。実際の入力間隔はAndroidと入力方式の処理時間に依存します。通常の遷移に追加の固定待機を設けず、新しい2枚の画像を確認して進めます。広告の終了待ちと、失敗時の再試行間隔は残しています。

## 検証

43組のホストテストを実行しました。今回の買い物うさぎの録画テストは1,044項目です。売り場・倉庫・品出し・来店獲得・予約・強化・ミッション・広告の画面、実際の各操作位置、カウントダウンとの区別を確認しています。変動する紙幣と数値がある倉庫画面61枚でも、主画面の一致判定を確認しました。

複数行の「ゲット」と余白付き表示は合成した画像で検証しました。元の動画は編集済みの手動操作例で、旧版の実行ログではありません。端末への実際の入力と複数ウインドウの並列稼働は未確認です。全広告・全配置・全ゲーム状態に対応したという意味ではありません。

APKはversionCode 66、仮想実行部66です。従来と同じ更新用証明書、v2/v3署名、ネイティブライブラリの16KiB配置を検証しています。

## 再ビルド

ソースZIPのTapMarkerディレクトリで実行します。API 35 / Build Tools 35.0.0とJavaが必要です。

```sh
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/update-key.jks \
bash build.sh

ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
```

更新用の秘密鍵と元の動画はZIPに含めません。独自の鍵で署名したAPKは今回のAPKへ上書きできません。

録画の検証データ・根拠・再生成スクリプトはtests/video6666-*、tests/prepare-video6666.pyに含めます。画像見本はassets/shopping-preset.jsonです。以前の動画の検証とライセンス情報もソースに含めます。
