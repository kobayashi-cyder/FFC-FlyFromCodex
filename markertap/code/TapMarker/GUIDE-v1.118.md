# MarkerTap v1.118 — 通常解像度への復帰

`jp.tapmarker.lite` / versionName `1.118` / versionCode `121`

仮想画面を端末の現在の通常解像度・DPIで作成します。
保存済みの320px等の指定を解除し、低解像度実験の選択操作を取り除きました。
負荷設定・メモリ圧迫時の軽量設定でも、ゲームの画素数・DPIは縮小しません。

## 更新手順

1. 旧版で「全停止」を押し、更新APKを上書きインストールします。
2. ユーザー補助と端末内接続を確認し、対象アプリの仮想画面を開き直します。
3. 「設定」→「仮想画面の起動解像度」→「解像度を確認」で予定値と現在値を確認できます。

既存の低解像度画面は、開き直した後から通常解像度になります。
パネルの縮小表示・見出しのみの表示は引き続き使えます。
画像配列の見積もりがJavaヒープの半分を超える場合は、画面数を減らす案内を出して起動を止めます。
これはゲーム・GPUを含めた端末全体のメモリ使用量を保証する基準ではありません。

## 検証状態

ビルド・core回帰試験・従来版との署名証明書一致・APKの16KB境界配置を検証済みです。結果はGitHubのmarkertap/releases内に保存しています。
Android実機での通常解像度の長時間稼働・広告動作・アプリ側の扱いは未検証です。
低解像度化を撤回する変更であり、対象アプリによる判定を保証するものではありません。
