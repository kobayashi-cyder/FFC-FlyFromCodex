# MarkerTap v1.94 — 農園の収穫連打の間欠停止を修正

パッケージ `jp.tapmarker.lite`、versionName `1.94`、versionCode `97`、実行部89。v1.93と同じ署名で上書き更新できます。

## 更新と開始

1. 旧版の「全停止」を押します。
2. `MarkerTap-v1.94-smooth-harvest.apk`を上書きインストールします。アンインストールは不要です。
3. ユーザー補助が有効なことを確認し、農園うさぎを開いて「自動開始」を押します。

プリセットへのマーカー配置・位置調整は不要です。仮想画面・PC表示を使う場合は、更新後に接続と表示を開始し直してください。保存した手動マーカー・学習・編集内容は維持します。

## 修正した動作

| 場面 | v1.94の動作 |
| --- | --- |
| 通常の収穫画面 | 存在しないダイアログやフィーバー見出しへの不要な全画面探索を抑制します。現在位置と以前に認識した位置の確認は継続します。 |
| ボタンが押下で移動・縮小する | 収穫文字の周囲を限られた範囲で先に照合し、見つからない場合は対象を再探索します。 |
| 通常・押下・フィーバー | 固定ヘルプと白い「収穫する」文字を同じ新しい画像で確認し、虹色への変化だけで連打を保留しません。 |
| 広告・宝箱・報酬・確認画面 | 通常連打を保留し、既存の画面別処理を優先します。 |
| 入力指示が保留される | 実行要求がONでも「連打保留」と表示します。回数は「送信完了」であり、ゲーム側の収穫回数ではありません。 |

画像の有効期限1.5秒は延長していません。古い画像を根拠に連打する猶予は追加していません。

プリセットのマーカー自動配置・表示は廃止したままです。位置変更への再認識、他ゲームの既存処理、通常連打と強化処理の分離、F-52Aの離散入力、コイン落としの任意CM除外、ポイポイうさぎの「使用しない」は引き継ぎます。見た目そのものが変わった未見のUIは新たな録画・学習が必要です。

## 検証

録画6732.mp4の26場面を原寸で検証しました。通常・押下・フィーバー20場面、広告等の割込み6場面を含みます。この動画から画像テンプレートは追加していません。

同じ20場面の連続サンプリングで、v1.93は収穫対象を3場面で見失い、v1.94は20場面すべてで確認しました。画素参照要求は292,524,528回から1,914,624回へ減少しました（約99.35%削減）。広告等を含む全26場面では498,903,312回から165,528,884回です。ホスト上の同じ画像・同じ処理順での計測で、Android上の速度や実際の収穫数ではありません。

録画6732の新規検証は149項目で、押下表示からの新規開始、割込み、古い画像での保留を含みます。以前の農園フィーバー検証71項目を含む100組のJava回帰と、模擬ADB8シナリオも合格しました。結果はソース内の `tests-v1.94.log` と `VALIDATION-v1.94.json` に記録しています。

最終APKの署名・16KB配置・4種類のCPU向けライブラリ・DEXと検証済みJava入力の対応を確認しています。Android実機は接続していません。入力受付・ライブのゲーム反応・端末上の実効速度は未確認です。

## 再ビルド

Java17、Android API35、Build Tools35.0.0、同梱ECJを使用します。元の更新署名鍵を指定してください。署名鍵は配布ソースに含めません。

```sh
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/lite-development.jks \
bash build.sh
ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
```

更新用証明書SHA-256：

```
7f42d636e4d3c251f475eb998fbe8e92b515ded8bce3ff4d30aa90b9a738cfb1
```

録画フィクスチャは `python3 tests/prepare-video6732.py /path/to/6732.mp4` で再生成できます。元動画は同梱しません。
