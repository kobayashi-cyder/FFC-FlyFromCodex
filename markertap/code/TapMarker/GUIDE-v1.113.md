# MarkerTap v1.113 — ポップアップと報酬回収

`jp.tapmarker.lite` / versionName `1.113` / versionCode `116`

## 更新

1. 旧版で「全停止」。
2. `MarkerTap-v1.113-popup-reward.apk` を上書きインストール。
3. 「端末だけで接続」で再接続し、「自動開始」。

既存の署名を維持する。設定を消す再インストールは不要。起動幅320px・選択アプリ・画面数の設定は変更しない。実行部のプロトコルはrevision 91のまま。

## 改修内容

- 農園とポイポイのゲーム内ポップアップを、詳細な主画面探索より先に確認する。対象アプリ・対象ディスプレイに属する各ウインドウを調べ、独立したダイアログのルートも確認する。
- オフラインという見出しと通常の「獲得」「受け取る」などのボタンが確認できれば、実際のボタン位置を利用する。農園に通常のオフライン獲得から画面再判定へ戻る分岐を追加する。
- 「×」はゲーム内のダイアログ文脈で確認する。画像では色付きの見出し帯と白い本文からなるパネルを測定し、その内部右上の黒い×を確認する。広告の画面隅だけに依存しない。あらゆる外観のポップアップを認識する保証ではない。
- ポイポイの通常オフライン獲得は既存の2領域画像でも先に確認する。CM倍率のボタンとは別に扱う。
- ポイポイのゲットは複数の縦方向の確認位置を利用する。見出しとボタンの拡大率が縮小画像でずれる場合には、それぞれの文字照合を条件として元の倍率でも再確認する。
- ゲットが見つからないだけではミッションから戻らない。表示中の操作ボタンを「プレイ」と積極的に確認できたときだけ、戻る分岐を許可する。判別不能なら画像を再取得する。これは表示範囲の判定であり、全デイリー達成の証明ではない。
- 獲得操作の入力完了と、その後の報酬画面・一覧変化の確認を診断履歴で分ける。主画面へ戻ったことや×を閉じたことだけで報酬獲得を確認済みにしない。加算額は未検証として記録する。
- 独自編集・学習したオートマトンには新しいポップアップ経路を自動追加しない。既定の状態機械へ実行時だけ追加する。

## 実機で確認する点

今回の2026-10-20の実機画面・録画は提供されていないため、止まったポップアップの外観を再現できていない。ゲームが文字やボタン位置をユーザー補助へ公開せず、上記の画像条件にも合わない場合は、追加の画面資料が必要。

Pixel 10 / Android 17の実機での入力到達・実際の報酬加算・4画面の長時間稼働は未確認。ホストのテスト結果とAPK検証結果は `VALIDATION-v1.113.json` と `tests-v1.113.log` に記録する。

