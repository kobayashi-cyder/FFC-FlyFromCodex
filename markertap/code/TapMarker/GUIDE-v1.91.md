# MarkerTap v1.91 — ポイポイうさぎの標準自律

パッケージ `jp.tapmarker.lite`、versionName `1.91`、versionCode `94`。v1.90の後継です。

## 更新と開始

1. 旧版で「全停止」を押します。
2. `MarkerTap-v1.91-poipoi-autonomy.apk` を上書きインストールします。
3. ユーザー補助の「マーカー連打」が有効なことを確認します。
4. 「ポイポイうさぎ」を開いて、操作パネルの「自動開始」を押します。

マーカーがなければ、にんじんの位置に自動配置します。停止は「全停止」です。既存の独自設定がある場合は保持するため、新しい標準処理を使うには、停止後に「かんたん編集」→「図で編集」→「初期設定へ戻す」を選びます。元のオートマトンは退避します。

対象アプリは `com.kurashiru.poipoi.usagi` です。増えうさぎ、農園うさぎ、コイン落とし、買い物うさぎ、ボックスマージとは別の設定・画像・状態で扱います。

## 追加した動作

| 表示・状況 | 処理 |
| --- | --- |
| オフラインボーナス | 通常の「獲得」を押す |
| 通常プレイ | にんじん付近へのタップを繰り返す |
| 満足度100.00% | 通常タップを保留し、ミッションを開く |
| ミッションの赤い通知 | ミッションを開く |
| デイリーミッション | 画面に見える達成済み「ゲット」だけを押す |
| 表示中にゲットがない | 左上の戻るを押して通常プレイへ戻る |
| コイン獲得 | 「閉じる」を押し、回収の続きへ戻る |
| コインアップチャンス | 「このままはじめる」で継続 |
| 録画のCM | 広告の連番表示と配信元表示を2枚の新しい画像で確認し、ホーム経由で元ゲームへ戻る |
| 回収中の連続CM | 回収中の状態を保ち、復帰後に報酬・ミッションを再確認する |

途中の満足度、うさぎの種類・動き、にんじんの動きだけでは連打を中断しません。100.00%の文字は、通常画面の固定表示で決まる位置で照合します。数字に合わせて判定範囲を動かさず、途中の数値との誤認を防ぎます。

満腹の表示や通知を取り逃した場合に備え、通常プレイを1分継続した際にもミッションを確認します。画面に見える「ゲット」がなければ戻ります。未達成の黄色い「プレイ」、任意のオートタップ・タップ2倍・キャラクターチェンジのCMは開始しません。

CMで「Open Google Play」の矢印を終了候補として押しません。録画と一致する2つの広告表示が確認できなければ、既存の×・閉じる・スキップ・戻る・登録アプリへの復帰を使用します。ホーム画面が表示されたことを確認してから元ゲームを開き、通常プレイを認識するまで連打を保留します。

## 対応範囲と検証

録画6725の、見本と時点が重複しない137枚（原寸画像8枚を含む）で1,370項目の検証を行いました。通常プレイ、満腹、オフラインボーナス、継続、ミッションのゲット・プレイ、獲得報酬、連続CM、Androidホーム、表示切替中の画像を含みます。目印の欠落、古い画像、画像通知の重複、サイズ変更、操作直前の画面変化も検証しています。

配布APKと同じ縮小済みJavaクラスで、既存のcore回帰テストを実行します。記録は `tests-v1.91.log` と `VALIDATION-v1.91.json` に含めます。従来の4種類のCPU向け構成（arm64-v8a、armeabi-v7a、x86、x86_64）を維持します。

ミッション一覧の自動スクロールや未撮影の確認画面、デイリー全件完了の自動判定は含みません。前面の単一画面では早期のホーム復帰を使い、複数画面・仮想画面では従来の画面別の戻る・復帰を使用します。

Android実機は接続されていません。F-52A・Pixel 10での入力反応、ゲーム側での報酬付与、ホーム復帰と複数画面の挙動は未検証です。
