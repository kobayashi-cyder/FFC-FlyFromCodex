# MarkerTap v1.107：共有解析回路とオートマトンの実行時正規化

`jp.tapmarker.lite` / versionName `1.107` / versionCode `110`

## 更新と操作

1. 旧版で「全停止」を押し、仮想画面を閉じます。
2. `MarkerTap-v1.107-frame-circuit.apk` を上書きインストールします。以前と同じ署名鍵で署名します。
3. 仮想画面を作り直して「自動開始」を押します。

v1.106の増えうさぎの「ゲット」対応と、操作パネル内の見出しプルダウンを含みます。「仮想画面 ▾」から見出し一覧を開き、見出しまたは「拡大」で該当する既存の仮想画面を表示、「収納」で見出しへ戻します。収納中も元画像の取得と自律処理を継続します。詳細は `GUIDE-v1.106.md` を参照してください。

## 新しく組み立てた処理回路

既存BANCの接続情報の抽出は行いません。要求確認・元画像の複製・鮮度確認・画像解析・再確認・結果通知・取消し・参照解放という8ノードの接続を新規に定義しました。`FrameCircuit` がその接続表に従って実際に処理を実行します。

従来は各仮想画面が元画像latestと解析用snapshotをそれぞれ保持していました。新方式では各画面の元画像を維持し、解析用バッファを1つのワーカーで共有します。画面の取得、ゲームへの入力、プレビュー更新は引き続き別の非同期経路を使います。重い画像解析の同時実行数は1つになります。

解析中だけ画素の参照を貸し、解析後は無効化します。UIへ渡すのは判定結果と寸法・時刻だけです。停止・画面の作り直し・古い時刻・例外・メモリ不足を扱い、閉じる時やメモリ圧迫時には共有バッファを解放します。診断レポートに回路の保持バッファ量・完了数・取消し数を追加しました。

画像認識や入力判定の各関数は既存のものを使います。全アルゴリズムを神経モデルへ置換したものではありません。

## オートマトンの正規化

保存設定には従来から同じルール・状態の安全な整理と画像見本の共有があります。今回、画面適応や広告復帰の組込みが終わった実行用オートマトンも正規化するようにしました。

- 通常の画像見本、補助見本、通常画面用の代替見本、複数の組合せ見本を、float値の完全一致で共有します。近い画像を丸めて統合しません。
- アプリ間、保存設定と実行モデルの間には共有プールを作りません。各ルールの補助見本の行コンテナも独立させます。
- 実行時の正規化は状態・ルールのIDや順序、履歴、確認回数、タイマーを維持します。操作制御側から名前で参照する状態も残します。
- 構造の正規化では、実行時の代替見本・距離計算方法・制御表示の条件が違うルールも別扱いにしました。箱・ポイポイのプリセットも識別が必要な状態として保護します。

## 実測の読み方

`FRAME-CIRCUIT-RESULTS-v1.107.md` とJSON・ログに結果をまとめます。画像バッファは、同じ録画画素・同じ認識関数で旧保持方式と新回路を実行し、実際に確保した配列をInstrumentationで測定します。正規化は同じ初期モデルを組み立て、エンジン・レイアウト・強化処理から到達できるオブジェクトを重複排除して測定します。

この測定にはAndroid端末、ゲームプロセス、GPU、ImageReaderのnativeバッファは含まれません。実機PSSやピークRAMではありません。ホストの処理時間も、Androidの同時解析の総処理能力や長時間運転を示しません。

仮想アプリの選択上限は従来どおり2です。省メモリ化だけを根拠に、端末で動くアプリ数を保証することはできません。見出しの端末上の描画・タッチ操作、実際の入力配送・報酬加算、長時間運転は実機未確認です。

## 再実行

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/original-key.jks \
bash build.sh

ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
bash tools/memory-probe/run.sh > normalization-memory-v1.107.log
java -javaagent:build/memory-probe-agent.jar \
 -cp build/memory-probe:build/shrunk.jar:build/test-classes \
 jp.tapmarker.FrameCircuitReplayBenchmark FRAME-CIRCUIT-BENCHMARK-v1.107.json
```

元の署名鍵はソースZIPに含めません。通常回帰のcore群を実行し、復元元に録画fixtureがない旧full群4本は引き続き対象外です。
