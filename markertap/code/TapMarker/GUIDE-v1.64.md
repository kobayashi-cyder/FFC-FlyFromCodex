# MarkerTap v1.64

容量削減、農園うさぎのフィーバー認識、外部画面での連打保留、重複オートマトンの整理を加えた更新版です。増えうさぎ・農園うさぎ・コイン落とし・買い物うさぎと、アプリ別の編集・観察学習を含みます。

## 更新と開始

1. 旧版で「全停止」を押し、仮想ウインドウを閉じます。
2. MarkerTap-v1.64-compact-farm.apk を上書きインストールします。従来と同じ署名なので、アンインストールは不要です。
3. 仮想ウインドウを使う場合は、更新後に「端末だけで接続」から接続し直し、ウインドウを開き直します。実行部の版は67です。
4. 農園うさぎを開いて「自動開始」を押します。フィーバー中の色変化とボタンの押下表示を判定に含め、主画面を確認してから収穫連打を再開します。

このAPKはPixel 10などのarm64端末向けです。保存済みの独自設定は読み込み、完全な重複を整理してから利用します。

## 容量と重複の整理

| 対象 | 前版 | 今回 |
| --- | ---: | ---: |
| APK | 15,092,120 bytes | 4,220,897 bytes |
| 標準4アプリの画像見本配列 | 1,923,080 bytes | 233,480 bytes |

APKは約72%削減しました。端末に必要なarm64のネイティブライブラリを収録し、未使用のJavaライブラリ部分を除去しています。通信・ペアリング、Shizuku、学習用の回路データは含みます。回路は学習済み操作の判定などで必要になったときに読み込みます。

同じ画像見本と補助領域見本は、数値を丸めずに共有します。保存時は画像を一度だけ記録し、矢印から参照します。設定と実行用コピーの間は独立しています。

独自オートマトンでは、名前、条件、領域、操作、遷移先、優先度、待ち時間、安定時間、履歴条件、画像見本などが完全に同じ状態・矢印を統合します。同じ識別子・同じ内容の重複記録も一つにします。履歴が参照する識別子、標準設定の識別子、現在・開始状態、タイマーのリセット動作を変える状態は保持します。条件が異なる分岐は統合しません。初回の保存形式変更前に、元の設定を圧縮して退避します。

広告復帰用の状態・矢印も、再登録で増えないようにしました。

## 動画6669での変更

農園の固定ヘルプ表示と「収穫する」の白い文字を組み合わせて主画面を確認します。虹色のフィーバー背景に左右されにくい見本と、押下中の文字の見本を追加しました。以前の通常画面・仮想画面の見本も保持しています。

登録ゲームと異なるアプリが前面に出た場合、収穫の確認状態を解除し、連打を保留して復帰を待ちます。ゲームの表示を再確認してから再開します。

録画の26場面（1080×2424）を再生して検証しました。12秒・22秒を見本とし、それ以外の主画面19場面で確認しています。旧判定の取りこぼし11場面を改善しました。17秒・18秒・24秒の広告、54秒のブラウザ、55秒のウインドウ切替中は連打を保留し、58秒以降の主画面は認識しました。

## 再ビルド

ソースZIPのTapMarkerディレクトリで実行します。API 35 / Build Tools 35.0.0、Java、Python 3、rgが必要です。

```sh
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/update-key.jks \
bash build.sh

TAPMARKER_TEST_GROUP=core \
ANDROID_SDK_ROOT=/path/to/android-sdk \
bash run-tests.sh
```

暗号テストにはC/C++コンパイラも使います。TAPMARKER_TEST_GROUP=coreは同梱の小さい検証データで実行でき、4本の大きい録画再生試験を除外します。省略時は全試験を実行します。

配布ソースにはビルド用の依存ライブラリ、各ABIのネイティブライブラリ、見本、試験コード、結果、根拠データを含めています。容量削減のためtests/video6651-replay.bin.gz、video6662-replay.bin.gz、video6666-replay.bin.gz、video6669-replay.bin.gzを除外しています。過去の録画列を使う場合は前版ソースからコピーしてください。6669の列は元動画から再生成できます。

```sh
python3 tests/prepare-video6669.py /path/to/6669.mp4
ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
```

全ABI版をビルドする場合はTAPMARKER_ABIS=arm64-v8a,armeabi-v7a,x86,x86_64を指定します。更新用秘密鍵と元動画はZIPに含めません。別の鍵で署名したAPKは今回のAPKへ上書きできません。
