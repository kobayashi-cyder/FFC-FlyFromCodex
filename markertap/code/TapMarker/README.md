# マーカー連打 v1.97：CM処理と復帰監視の修正

`jp.tapmarker.lite` / versionName `1.97` / versionCode `100`

復旧した元の署名鍵で署名済みの更新版です。v1.96までのコイン落とし・ポイポイうさぎの認識と入力時間の修正も含みます。

## 今回の変更

- CM終了ボタンや登録済みの画面遷移を、BANCの操作結果待ちより先に処理します。以前は結果待ちの判定が先に戻り、画面に終了ボタンやゲームが出ても最長15秒、その処理を塞ぐ経路がありました。単画面と複数画面に共通の優先処理を入れています。
- 終了ボタンを押した直後もCMの監視を続けます。Androidからの入力完了通知だけでゲームへ復帰したとは判断せず、次のCMカードやゲーム画面を画像で確認します。ミッション中は回収経路を保持します。
- 標準対応6ゲームの通常・ミッション状態でも小さな上隅領域を確認し、CM割込み後に実際に見えた終了印を扱います。ゲームの一致画像が見えている場合は古い終了印と座標を無効にします。
- 終了ボタンの操作直前には、現在のゲーム・登録画面が戻っていないかも再撮影して確認します。
- Android 14以降のウインドウ単位の画像取得では、操作パネル等の無関係なイベントで画像を破棄せず、対象のパッケージ・ウインドウID・範囲を確認します。対象の切替・移動・サイズ変更があれば古い画像を破棄します。
- 終了印への入力要求は、中断・拒否・再確認失敗を含めて回数を制限します。再確認や入力中断でCM状態の復帰期限を延長し続ける経路を除きました。同じ位置への最大2回、CM全体8回の上限と、終了印が現れない場合の戻る・登録アプリへの復帰処理を使います。
- 録画18秒の「Google Play」ブランド表示内の三角と棒を、単独のスキップボタンとして操作しないようにしました。
- 小さいパネルでは自律のON/OFFと現在の判断を先に表示し、最大6行にしました。

独自に編集・学習したワークフローの遷移は優先します。停止指示や終了状態、アカウント等の保護状態は維持します。

## 録画と検証の意味

提供された `6742.mp4` の14枚を元の1080×2424のRGB画像として抽出しました。認識用の見本をこの録画へ合わせて追加してはいません。26秒、34秒、36秒の実際の終了印、動画中、ストア画面、終了印の出る前のカード、農園の通常画面を検証に使います。入力の完了通知、ウインドウイベントの順序、CMを繰り返す時系列は模擬です。

v1.96にも今回の本物の終了印を認識する処理はあり、録画だけから実機で止まった唯一の原因や、誰がタップしたか、録画時のAPK版を確定することはできません。今回は結果待ちの優先順位、入力完了後の状態、画像の有効性、再試行の期限というコード上の停止経路を修正しています。

新規 `Video6742ReplayTest` は706項目に合格しました。録画画素による終了印・ゲーム復帰・誤操作抑制と、模擬した複数CMの3周、BANC結果待ちの割込み、中断・遅延結果、ウインドウ識別、6ゲームの標準状態を確認します。従来のポイポイ回収3周とコイン入力の検証も継続します。

通常の回帰対象は既定の `core` 群です。追加の `full` 群4本（Video6651/6662/6666/6669）は、復元したv1.96ソースに録画画素のfixtureが同梱されておらず、今回未実行です。

通常回帰103組、模擬ADB8ケースが完了しました。ポイポイの次カードの確認を追加した追試は `ad-continuation-final-v1.97.log` に記録しています。最終の実行結果と署名・内容検証は `tests-v1.97.log`、`VALIDATION-v1.97.json` に記録しています。**この環境にAndroid実機は接続していません。端末上のCM後の継続動作と、すべての広告への成功率は未確認です。**

## 再ビルド

Java 17、Android API35、Build Tools35.0.0、Python3、ripgrep、C/C++コンパイラを使用します。

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/lite-development.jks \
bash build.sh

ANDROID_SDK_ROOT=/path/to/android-sdk \
bash run-tests.sh
```

再署名だけなら、同梱の `release/MarkerTap-v1.97-unsigned.apk` と `sign-release.sh` を使います。`sign-release.sh` は元の証明書と一致しない鍵では出力を中止します。
