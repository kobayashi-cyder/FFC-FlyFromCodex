# MarkerTap v1.119 領域取得・差分表示
端末の通常解像度・DPIを維持します。旧低解像度指定はv1.118同様無効です。

オートマトンの現在の監視領域・ガード・操作後確認領域を先に渡します。
元のImageReaderバッファから必要な32pxタイルを直接読みます。
全画面ARGB配列への変換と認識用全配列コピーは通常経路から廃止しました。
位置補正・広告・日次完了などグラフ外の補助検出も、同じ画像から必要タイルを追加取得します。
欠けた画素をゼロや「不在」に置き換えません。

プレビューは必要領域だけを小さなパッチで表示します。新しい画像で画素一致を確かめたパッチは既存Bitmapを再利用します。
状態・領域定義・表示世代・サイズの変更時に表示キャッシュを破棄します。
新しい判定画像・状態・世代・鮮度の確認は維持します。
手動操作・学習・明示的な画像取得では全体表示や全サイズBitmapを要求することがあります。

ImageReaderの画像を参照カウントで保持し、解析終了まで元画像とそのReaderの解放を遅らせます。解析中も新しい表示画像へ差し替えられます。
取得上限は最新画像1枚・解析用リース1枚・acquireLatestImage用2枚分の4。複数画面の解析は既存FIFOワーカー、入力は画面別レーンです。
通常経路のタイルキャッシュは1消費者あたり64タイル（256KiB）です。OS・GPUの通常解像度バッファは別に存在します。
上限4と従来の保守的なメモリ判定は維持しています。

実装をGitHubへ保存済み。ビルド・署名・回帰試験は実行待ちです。
実機の表示・入力・GPU読み戻し・多重化可能数は未確認です。画面数増加や対象アプリ側の判定は断定しません。
