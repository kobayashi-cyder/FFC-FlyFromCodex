# MarkerTap v1.80 — コイン落としの任意CM視聴を削除

パッケージ `jp.tapmarker.lite` / versionName `1.80` / versionCode `83`。
`MarkerTap-v1.80-coin-no-ads.apk` を上書きインストールしてください。v1.79と同じ署名・パッケージです。アプリの削除は不要です。

## 変更した動作

| 画面・操作 | v1.80の処理 |
| --- | --- |
| レアコイン出現率アップの任意CM | CMを押さずキャンセル／戻る |
| ポケット倍率アップの任意CM | CMを押さずキャンセル／戻る |
| タップ2倍の任意CM | CMを押さずキャンセル／戻る |
| ポット数増加の確認 | v1.79のキャンセル処理を継続 |
| ステージ開始の「このままはじめる」 | CMを選ばず開始 |
| 通常プレイ | 通常タッパーで連打を継続 |
| 確認画面・広告・報酬処理中 | 通常連打を保留 |
| ゲームが自動表示した広告 | 終了印・戻る・登録アプリへの復帰を使用 |

任意CMの「CMをみてゲット」をタップする操作を取り除きました。既存の画面識別用にCMボタンの画像見本は残しますが、その座標をCM開始の入力には使いません。

確認済みの強化画面でキャンセル文字が見えるときは、その文字を新しい画像2枚で確認します。ゲームの説明・操作部の見本とキャンセルの文字が揃った場合にだけキャンセルへ入力します。マーカーに隠れていない右側の文字を使います。

文字がまだ表示されていない、または確認できない場合は、CMを押さずAndroidの「戻る」を送ります。入力後は1.2秒の再入力待ちを設け、通常画面を改めて確認してから連打を再開します。ポット数増加はv1.79の消失確認・再判定を使います。

ゲーム側で自動表示される広告そのものを非表示にする改変ではありません。任意視聴は選ばず、既に表示された広告から戻る処理は保持します。旧「強化CM待ち」の120秒の待機は30秒へ短縮し、終了印が見つかればその操作を優先します。

## 設定の引き継ぎ

未編集の標準オートマトンは自動移行します。単画面・仮想画面では実行用コピーにもこの方針を適用し、旧標準由来のCM開始操作が保存設定に残っていても実行時はキャンセル／戻るへ変換します。編集済みの保存データ自体は上書きしません。

独自に登録した任意の座標入力について、CMボタンかどうかを画像なしで判定する変更ではありません。今回の変更は既存のコイン落とし標準識別・標準操作が対象です。他のゲームの視聴方針は変更しません。

## 操作

上書き後にコイン落としを開き「自動開始」を押してください。Androidがユーザー補助を停止した場合は「マーカー連打 軽量版」をOFF→ONにします。

## 確認した範囲

`CoinNoAdPolicyTest` の77項目は、提供画像由来の文字見本と、既存録画の評価用画像を使用します。任意CM開始の除外、見えているキャンセルへの入力、キャンセル非表示時の戻る、入力直前の再確認、座標の失効、通常画面を確認してからの再開、既に表示された広告の終了、標準設定の移行、他ゲームへの影響、BANC経由のCM付きゲットの除外、編集済みの停止操作を維持することを検査します。縮尺変更・余白・文字の欠落と時系列の一部は合成条件です。

v1.79のポット増加画面の200項目と既存core回帰検査も実行します。配布APKと同じ縮小済みJavaランタイムを検査対象とし、APKの署名・版・DEX・アセット・4種類のCPU向けライブラリ・16KB配置も確認します。

F-52Aへの実入力、キャンセル／戻るをゲームが実際に受け付けることは、この環境では未検証です。記録画像にない全種類の広告・端末UIの成功率を示す検査ではありません。
