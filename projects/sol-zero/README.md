# Sol-Zero v0.11 — ゼロから構築するチャット＋帰納WSP

**Qwenなどの既存学習済み重み・蒸留・外部推論APIは一切使用していません。**

## 使い方

1. `SolZero_Chat_Offline.html` をブラウザで開く（外部CDNなし）。Android/PCで使用可能ですが、ブラウザの `file://` 保存制限に注意してください。
2. 上部の **「帰納WSP」** を開く。訓練データと独立した評価データのJSONを編集できます。
3. **「① 候補回路を合成して独立検証」** を押す。曖昧・不一致の場合は採用しません。
4. 成功した場合だけ **「② 合格回路だけ採用」** を押す。
5. チャットで `/induce 2,3` と入力すると、導出された現在の数値回路を実行。以前の回路へはパネルから復元できます。既存の `/graph 2,3` も利用可能です。

`/intent` のスクラッチ学習済み6分類器、保存知識、タスク、資料検索、WSP回路工房、状態遷移回路、文字予測実験、会話履歴、バックアップなどv0.10の機能は維持しています。

## 中核の仕組み

- `chat_web/wsp_induction.js` — 数値の入出力例から候補関数を列挙、一次結合の重みを訓練例だけから最小二乗で推定、重み行列を含むグラフへ変換。
- `chat_web/wsp_graph.js` — WSPの実行・重み直接編集・ロールバック。
- 候補が訓練例で同点の場合は固定プローブ入力で一致しないことを検出。新しい例を要求し、**勝手に正解と決めません**。
- 評価例は訓練とは重複禁止。規則選択への利用禁止。評価が全件成功したときに限り、改ざん耐性を持つ採用関数を呼び出せます。
- 動的JSコード実行（`eval`/`Function`）、外部ネットワーク、外部学習済みモデルは使用していません。

## 検証手順

```bash
node --test tests/*.test.mjs
python -m pytest -q tests/test_solzero.py tests/test_weight_store.py
node training/benchmark_induction.mjs --write
python scripts/build_standalone.py
```

ブラウザ試験環境がある場合：`python scripts/browser_induction_smoke.py`（PlaywrightとChromiumを別途用意）。

## v0.11 実験の結果と限界

| 対象 | 結果 |
|---|---:|
| Node.js単体・回帰試験 | 95/95 |
| Python基礎試験 | 13/13 |
| 合成数値問題（各20件：一次結合・積・絶対差・最大・最小） | 100/100 |
| 数値問題の未使用評価入力 | 訓練 -9〜9、検証10〜30 |
| 旧v0.10の指示分類 | 別実験・学習済み重み24,582個、324件中287件正解 |

**100/100は事前に用意した小さな演算候補群でのスコアです。** 未知の一般的なプログラミング、自然言語の自由回答、画像理解、Sol級知性には到達していません。評価の信頼性を確認するには、候補外の関数・桁の大きい値・ノイズのある実データを追加する必要があります。

完成品の保存容量は **5,000,000,000バイト以下** に制限。配布サイズと実行時RAM・学習時GPUメモリは別です。
