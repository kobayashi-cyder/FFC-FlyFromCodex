## v1.121 異常終了時の全停止（2026-10-21）
ソースは `code/TapMarker` に反映済み。AndroidManifest versionCode 124 / versionName 1.121。
アプリ未処理例外、所有アプリBinder死亡、仮想画面単独の起動失敗、ADB/Shizuku実行部異常終了、ユーザー補助割込み/終了を全停止経路へ統一。
実行部は所有者のBinderに紐づけ、死亡時はすべての仮想ディスプレイを開放。途中の例外でも他ディスプレイを開放。
クラッシュ後の自動再接続は抑止。利用者による明示開始のみ解除。
`GUIDE-v1.121.md` が詳細仕様。公開APKは現時点ではv1.120が最後の検証済み。v1.121配布APKはビルド・同一署名・実機検証前。
GitHub Actions `markertap-source-check.yml` は使い捨ての検証用鍵でコンパイル・回帰試験を実施（配布不可）。
本番署名ビルドには既存の非公開署名鍵の安全な提供が必要。Android 17 / Pixel 10 で残存画面数とshellプロセスの実機確認が未了。
