# MarkerTap v1.62

6662.mp4 に映っている「うさぎのコイン落とし」の画面を基に、アプリ専用のオートマトンを追加しました。増えうさぎ・農園うさぎの既存設定と、アプリごとの学習・編集機能を含む更新版です。

## 更新と開始

1. 旧版の「全停止」を押し、MarkerTap-v1.62-coin-video.apk を上書きインストールします。アンインストールは不要です。
2. 連打アプリを開き、必要なアクセシビリティ権限と画面上への表示権限を有効にします。
3. コイン落としを開き、パネルの「自動開始」を押します。初めての登録では専用の状態・矢印・領域を自動作成します。マーカーがない場合はコイン投入ボタンに一つ作成します。
4. 既にコイン落とし用のオートマトンを編集している場合、その設定は保持します。今回の初期設定を使うには、作成・編集画面の「初期設定へ戻す」を使ってください。現在の設定を退避して置き換えます。
5. 仮想ウインドウで使う場合は、更新前のウインドウを閉じ、端末内接続を再接続してから開き直してください。「自動開始」は表示中の対象ウインドウを操作します。

## 今回の処理

| 確認した表示 | 操作・次の状態 |
| --- | --- |
| 通常のゲーム画面 | この画面で補正したコイン投入位置を連打 |
| フィーバー表示 | フィーバー専用状態でコインを投入 |
| ミッションの赤い通知 | 連打を保留して、ミッションボタンを押す |
| ミッションの「ゲット」 | 表示中の各ボタンの文字を確認し、そのボタンの中央を押す |
| コイン獲得のダイアログ | ダイアログ内の「閉じる」を押し、ミッションへ戻る |
| ミッションの「プレイ」 | 未回収の「ゲット」が検出されない場合に押し、ゲーム画面の復帰を確認 |
| レアコイン・ポケット倍率の強化ダイアログ | 専用の CM ボタンを押し、広告終了の操作を待つ |
| ステージクリアの演出 | 投入を保留し、次の表示を判別 |
| コインアップチャンス | 動画で確認した「このままはじめる」を押して、次の画面を確認 |
| 広告の白い「×」・黄色い輪の「次へ」 | 有効な広告状態の隅だけを検査し、確認した印の中央を押す |
| ミッション処理中の外部アプリ・広告 | 登録アプリに復帰してミッションの確認を続ける |

コイン落としは 20 状態で、ミッション途中の復帰先と通常の復帰先を分けています。報酬を閉じただけではメイン連打を再開しません。入力送信が失敗した場合も表示の再確認を続けます。

## 表示の違いへの対応

画面ごとに見出しと操作ボタンの文字を組み合わせて確認します。主ボタンはタップ時に変形するため、その輪郭を主画面の判定には使いません。通常表示・仮想ウインドウの余白や縮小、ダイアログの拡大縮小に合わせて操作位置を補正します。

各アプリ・ウインドウは独立した状態と座標を使います。画面全体の画素を総当たりで走査せず、現在の状態の小さな目印、表示中の「ゲット」ボタン列の細い縦線、広告状態の上隅を確認します。画像取得そのものは OS が提供する対象画面のキャプチャです。

デフォルト間隔は 3ms です。Android の入力処理時間を含む実際のタップ間隔は端末と入力方式に依存します。

## 検証の範囲

42 組のホストテストが通りました。今回の録画によるテストは 625 項目です。v2/v3 署名、従来と同じ更新用証明書、versionCode 65、仮想実行部の版 65、ネイティブライブラリの 16KiB 配置を確認しています。

録画から抽出した画素を使い、場面判定、各操作位置、読み込み中の誤操作防止、広告の閉じる・次へ・カウントダウンの区別を確認しています。余白付き表示と、別の行へ移動した「ゲット」は合成画像による検証です。

録画は編集済みの操作例で、旧版の実行ログは映っていません。この録画だけから旧版の実機不具合の原因を断定していません。端末への実際の入力と複数ウインドウの並列稼働は未確認です。動画にない広告形式、画面外のミッション行、すべてのゲーム状態への対応を保証するものではありません。

## ソースからの再ビルド

ソース ZIP の TapMarker ディレクトリで実行します。

```sh
ANDROID_SDK_ROOT=/path/to/android-sdk \
TAPMARKER_KEYSTORE=/path/to/update-key.jks \
bash build.sh

ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
```

API 35 / Build Tools 35.0.0 と Java が必要です。更新用の秘密鍵はソース ZIP に含めません。独自の鍵で署名した APK は今回の APK への上書き更新には使えません。

録画画素の検証データと再生成スクリプトは tests/video6662-* と tests/prepare-video6662.py に含まれます。元の動画は ZIP に同梱していません。
