# MarkerTap v1.86 / MultiScreen PC 2.5

パッケージ `jp.tapmarker.lite` / versionName `1.86` / versionCode `89`。仮想実行部89、PC連携プロトコル1です。1.85と同じ署名で上書き更新します。

## 今回のエラーについて

2026-10-16 06:08の報告では、増えうさぎの入力完了652回の後、Androidが「指定UIDのウィンドウへの入力ではない」と拒否しています。ログには実際のウィンドウ所有者がないため、広告・別アプリ・表示の切替のどれが原因かまでは断定できません。入力完了回数はAndroidへの送信完了で、ゲーム内の反応を保証する数値ではありません。

全画面が停止した直接の理由は、従来のスマホ側プレビューの「×」が `s.stop()` を呼ぶ処理でした。UID拒否自体と、後のプレビュー終了による全停止は別の事象です。また、削除済みの画面がPCに残り、全体が停止しても「並行処理中」のままになる不具合がありました。

## 変更した動作

- UID不一致は、その画面だけ入力を保留します。表示先を確認し、同じ仮想画面へ登録アプリを戻して、新しい画像とアプリ表示を確認した後にゲームの状態判定をやり直します。
- 復帰要求は画面ごとに最大3回、間隔10秒以上です。復帰確認できない画面は待機し、ほかの画面のエンジンを停止しません。新しい入力が完了すると回数制限をリセットします。「自動処理だけ停止」後の再開始でも再試行できます。
- 入力先UIDと画面IDの制限を維持します。表示アプリが対象と異なる場合はタップせず、同じ復帰処理へ進みます。別UIDや本体画面への入力へ切り替える変更はありません。
- PC配置中のスマホ側プレビューでは「×」を「隠す」に変更しました。プレビューだけ非表示になり、仮想画面、画像判定、PC表示とTapMakerの処理は続きます。「仮想画面を拡大表示」または「仮想画面を最小表示」で再表示できます。
- 「すべて停止」「仮想画面を全て閉じる」は、従来どおり明示的な全停止操作です。
- PCは毎回のスマホ状態に画面一覧を合わせ、削除済みの表示を閉じます。全体が停止した時は、古い画像や過去の入力拒否があっても「停止」と表示します。過去の拒否理由と入力回数は診断に残します。
- 診断にはAndroidのバージョン・API・機種、表示アプリと入力先の再確認状態を追加しました。

## 更新して使う

1. 旧PC版で「すべて停止」を押してから終了してください。旧コンソール版が残っている場合は、その画面でQを押します。
2. `MultiScreen-PC-v2.5.zip` を「すべて展開」します。付属APKも同じフォルダーに置いたままにします。
3. スマホをUSB接続し、USBデバッグを許可して所有者ユーザー0でロックを解除します。
4. `START-WINDOWS.cmd` を開き、scrcpy 4.1の `scrcpy.exe` を指定します。
5. 「TapMakerを更新・設定」で付属 `MarkerTap-v1.86-pc.apk` を上書きし、スマホでユーザー補助が有効なことを確認します。APKを直接上書きインストールする方法も使えます。アンインストールは不要です。
6. PCで「接続・アプリ読込」を行い、スマホの「複数アプリを開いて自律」→対象選択→「配置方式へ」→「PC（PCに各画面を表示して自律）」を選びます。スマホ側の対象と順序を一度だけ渡します。接続待ちは2分です。
7. PC側から対象をチェックして「TapMakerで同時操作」を押す従来の方法も使えます。更新後は新しい実行部89を起動します。

PCは画面をscrcpyで表示し、既存TapMakerのゲーム別オートマトンとタッパーが処理します。「画面のみ起動」は自動操作を開始しません。PCの個別映像ウィンドウを閉じても自動処理は続くため、停止ボタンを使用してください。

## 確認する点

各行の入力完了回数、画像の経過時間、ゲームの映像を確認してください。「入力先の切替を検出」はその画面だけを復帰させている状態です。「この画面だけ待機」は復帰上限に達した状態です。必要な場合は停止して再開始し、エラー詳細を保存してください。

農園うさぎの画像が約116秒前だった理由、コイン落とし・買い物うさぎの入力0回の理由は、この報告だけでは確定できません。この版を使った実機の画像更新とゲーム反応の確認が必要です。

## 対応と検証範囲

Windows 10/11、Windows PowerShell 5.1、scrcpy 4.1と同じフォルダーのadb.exeを使用します。TapMakerのPC連携はAndroid11以降の所有者ユーザー0が対象です。

標準4ゲーム（増えうさぎ・農園うさぎ・コイン落とし・買い物うさぎ）と、端末に有効な独自オートマトンがあるアプリを使えます。保存された学習・編集設定を継承します。未設定のアプリは開始前に案内します。

APKビルド、既存署名との一致、Javaの入力制限・復帰ロジック、実際のPowerShell Workerと模擬ADB/scrcpyを使った状態同期を検証しています。利用者のWindows GUI、Androidの実際のIPC、ゲームへの実入力は未検証です。詳しい検証記録はPC ZIP内の `VERIFICATION.md` にあります。
