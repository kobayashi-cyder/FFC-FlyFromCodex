# MarkerTap v1.122 — Pixelロック画面描画保護

## 目的
Pixel 10 / Android 17 のロック画面で時計の数字が重なる表示異常を観察しました。これはAndroid SystemUIの表示であり、MarkerTapが直接描くものではありません。原因は未特定です。MarkerTapによる仮想画面・オーバーレイ・画像解析の負荷や介入をロック中に残さないようにします。

## 改修
- 画面消灯（ACTION_SCREEN_OFF）・端末ロック（KeyguardManager）を検知したら自律操作を停止し、仮想画面を閉じ、ADB/Shizuku実行部へ終了要求を送ります。1画面が停止した場合も全停止する既存のv1.121安全動作を維持します。
- ユーザー補助オーバーレイ（操作パネル・マーカー）をロック中は非表示にします。
- 仮想画面の生成・入力の有効化・フレーム取得、およびWi-Fi経由のバックエンド接続をロック中は禁止します。
- ロック解除（ACTION_USER_PRESENT、アクセシビリティの状態変化）を検知したらパネルのみ表示可能に戻します。**ゲームや仮想画面の自動再開は行いません。** 再開はユーザー操作が必要です。
- Androidのロック画面のレイアウトや時計フォントは変更しません。SystemUIの根本不具合である場合、OS更新や時計デザイン変更が別途必要です。

## 検証
- GitHub ActionsのAndroid 35ビルド・回帰試験、およびv1.121と同じ証明書によるv1.122署名・APK整合性の検証を予定します。
- Pixel 10実機でのロック画面における時計描画、画面消灯直後の仮想画面解放数の確認は**未実施**です。
- 画面消灯で自動操作は明示的に終了します。CM待機中などでも続行しません。

ビルド・既存core回帰試験・従来版との署名証明書一致・APKの16KB境界配置を検証済みです。ロック画面の描画異常への効果はPixel 10実機で未検証です。結果はmarkertap/releasesに保存しています。
