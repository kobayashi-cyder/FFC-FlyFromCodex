# マーカー連打 v1.58：通常画面・仮想画面の位置補正と継続運転

v1.57と同じ署名の更新版です。上書きインストールできます。

## 更新後の操作

1. `MarkerTap-v1.58-adaptive-layout.apk`を上書きインストールします。
2. 仮想画面を使う場合は「展開」→「端末だけで接続」→「接続を開始」で、更新した実行部に接続し直します。
3. 増えうさぎ・農園うさぎを開き、「自動開始」を押します。仮想画面の場合は「複数アプリを開いて自律」から対象を開いて開始できます。
4. 停止するときは「全停止」。再試行中も「状況」で各画面の状態を確認できます。

保存済みのペアリング鍵、アプリ別設定、連打間隔は維持します。初期設定はソース内の`WIRELESS-v1.53.md`を参照してください。

## 表示差の吸収

通常起動、分割画面、仮想画面に共通の補正処理を入れました。

- 主画面の見出しと操作ボタン付近の2つの目印から、内容の余白・位置・拡大率を確認します。
- 見つかった位置を画像判定とタップで共用します。ミッションの炎アイコン、個別の報酬ボタン、標準の中央連打位置も補正した座標を使います。
- 操作直前の再確認で位置が変わった場合は、その最新の位置をタップ先にします。
- 主画面に入るには、両方の目印と連続した画像の確認が必要です。
- 農園の位置合わせには、収穫ボタン上部の白・緑の輪郭を利用します。押下中の表示も録画の画素で確認しています。
- 既知の通常画面の見本も使えるように残しました。元の画素許容値で照合し、主操作ボタン付近も確認します。

画像照合は現在状態で必要な小領域と、操作確認用の目印に限定します。不一致時の位置探索は領域の近くと有限個の余白・拡大率候補を確認し、同じ探索を毎フレーム繰り返す頻度は最大1秒に1回です。認識済みの位置は再利用します。これは通常の状態遷移に1秒の待機を追加するものではありません。

補正対象は既定の増えうさぎ・農園うさぎの認識領域と標準中央マーカーです。独自に変更した領域・見本を優先し、独自マーカーの配置も維持します。補正は実行用のコピーで行い、保存設定へ書き戻しません。小窓の表示倍率から入力座標を計算せず、実際の内部画面の座標を使います。

## 動かし続ける処理

| 状況 | v1.58の動作 |
| --- | --- |
| 主画面を認識できない | 連打を保留し、画面の判定・位置の再確認を続ける。既知の画面を確認できたら対応する状態へ進む。 |
| 復帰を3回要求しても確認できない | 次の要求を8秒保留する。その間も画像を判定し、主画面・報酬・広告終了印の処理を続ける。 |
| 仮想画面への復帰要求が拒否される | 画面を停止状態に固定せず、復帰確認と再試行へ戻る。 |
| ミッションを4回押しても応答を確認できない | 操作の再試行を一時保留し、ミッション画面への変化を監視し続ける。未完了のままメイン連打へ戻さない。 |
| キャンセル操作の応答がない | 再試行を一時保留して画面確認を続ける。 |
| 通常画面で入力が中断・拒否される | 操作完了の遷移を記録せず、表示を再確認して再試行する。 |

各仮想画面の補正状態・試行回数・待機は独立しています。他の画面の処理を一括停止しません。既知の画面が確認できれば、復帰要求の待機中も適切な分岐へ進めます。

「全停止」、終了状態、設定された停止条件、アカウント操作の保護は維持します。連打間隔の初期値は3msです。実際の入力速度は端末とゲームの処理速度に依存します。

## 検証

35個のホストテストスイートを実行しました。新規テストは位置補正138項目、継続復帰31項目です。

- 動画6645と以前のスクリーンショットから取得した画素を使い、主画面、農園の押下表示、報酬の閉じる、広告終了印を確認。
- 同じ画像に上下・左右の余白を加え、表示位置の変化を認識し、補正後の入力先が対象ボタン内に入ることを確認。
- 同じ大きさの画面のまま余白が変わるケース、ミッションの再確認後の押下位置、主画面が見えているのにCMと判定する問題を確認。
- 別ゲーム、広告、暗くなった報酬背景、目印の部品が消えた画像を主画面として受け入れないことを確認。
- 再試行保留中もミッションへの実際の遷移を認識でき、古い操作結果で新しい状態を上書きしないことを確認。
- 従来のオートマトン、入力先指定、接続、暗号関連のテストを実行。

APKのv2/v3署名、従来版と同じ証明書、ネイティブライブラリの16KB境界配置を確認しました。結果はソース内の`tests-v1.58.log`と`validation-v1.58.json`に含めます。

**Android実機は接続されていません。上記は録画の表示画像と合成した余白による検証です。修正版を端末に導入した後の長時間の連続稼働、実際の内部描画画像、実際の通常画面での一致率は未確認です。** 未知の画面を認識済みとして操作するのではなく、監視と復帰を継続する実装です。

## ソースからのビルド

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk TAPMARKER_KEYSTORE=/path/to/your-key.jks bash build.sh
ANDROID_SDK_ROOT=/path/to/android-sdk bash run-tests.sh
```

Android SDK platform 35/build-tools 35.0.0、Java、Python 3、ripgrepが必要です。暗号テストにはC/C++コンパイラも使います。署名秘密鍵はソースZIPに含めません。
